#链表

**链表（Linked List）** 就是一串节点，每个节点存着自己的数据，还带着一个指针指向下一个节点，就这样一个串一个。

> 与数组不同，链表**不需要连续的内存空间**，节点的内存可以是分散的，通过指针建立逻辑上的先后关系。

![](https://r2.salix.eu.org/obsidian/20260710145605998.webp)

### 链表的核心特点

- **动态大小**：链表大小不受固定限制，可动态增长
- **非连续内存**：节点分散存储，通过指针连接
- **插入/删除快**：已知位置时 $O(1)$，只需修改指针
- **随机访问慢**：无法像数组那样直接访问，需要遍历 $O(n)$

### 链表的类型

#### 1. 单向链表（Singly Linked List）

每个节点只保存指向**下一个**节点的指针：
```
[data|next] → [data|next] → [data|null]
```

#### 2. 双向链表（Doubly Linked List）

每个节点保存指向**前一个**和**后一个**节点的两个指针：
```
null ← [prev|data|next] ⇄ [prev|data|next] → null
```

#### 3. 循环链表（Circular Linked List）

尾节点指向头节点，形成环：
```
↓                          ↑
[data|next] → [data|next] →
```

### 链表的基本操作

| 操作 | 单向链表 | 双向链表 |
|:---|:--------|:--------|
| **头部插入** | $O(1)$ | $O(1)$ |
| **尾部插入** | $O(n)$（需遍历） | $O(1)$（有尾指针） |
| **中间插入**（已知位置） | $O(1)$ | $O(1)$ |
| **删除**（已知位置） | $O(1)$ | $O(1)$ |
| **按值查找** | $O(n)$ | $O(n)$ |
| **按索引访问** | $O(n)$ | $O(n)$ |

### 代码实现

#### Java

```java
/* 单向链表节点定义 */
class ListNode {
    int val;
    ListNode next;
    ListNode(int x) { val = x; }
}

/* 创建链表：1 → 2 → 3 → null */
ListNode head = new ListNode(1);
head.next = new ListNode(2);
head.next.next = new ListNode(3);

/* 头部插入 */
ListNode newNode = new ListNode(0);
newNode.next = head;
head = newNode;

/* 遍历 */
ListNode cur = head;
while (cur != null) {
    System.out.println(cur.val);
    cur = cur.next;
}
```

#### C++

```cpp
/* 单向链表节点定义 */
struct ListNode {
    int val;
    ListNode* next;
    ListNode(int x) : val(x), next(nullptr) {}
};

/* 创建链表 */
ListNode* head = new ListNode(1);
head->next = new ListNode(2);
head->next->next = new ListNode(3);

/* 头部插入 */
ListNode* newNode = new ListNode(0);
newNode->next = head;
head = newNode;

/* 遍历 */
for (ListNode* cur = head; cur != nullptr; cur = cur->next)
    cout << cur->val << endl;
```

#### Python

```python
# 单向链表节点定义
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

# 创建链表：1 → 2 → 3 → None
head = ListNode(1)
head.next = ListNode(2)
head.next.next = ListNode(3)

# 头部插入
new_node = ListNode(0)
new_node.next = head
head = new_node

# 遍历
cur = head
while cur:
    print(cur.val)
    cur = cur.next
```

### 单链表的存储密度

单链表的存储密度是指节点中有效数据所占的存储空间与整个节点（包括指针域）所占存储空间的比值，通常小于 1。

```
存储密度 = 数据域大小 / (数据域大小 + 指针域大小)
```

- 单向链表每个节点多用一个 `next` 指针
- 双向链表每个节点多用两个指针（`prev` + `next`）

### 数组 vs 链表

| 对比维度 | 数组 | 链表 |
|:--------|:----|:----|
| 内存分配 | 连续空间 | 分散空间 |
| 随机访问 | $O(1)$ | $O(n)$ |
| 头部插入 | $O(n)$ | $O(1)$ |
| 中间插入 | $O(n)$ | $O(1)$（已知位置） |
| 缓存局部性 | ✅ 友好 | ❌ 不友好 |
| 额外空间 | 无 | 指针域开销 |

### 应用场景

- **频繁插入/删除**且不常随机访问时（如 LRU 缓存）
- **不确定数据量**时，链表动态扩容无额外开销
- **双向链表**：实现 LRU 缓存、Java 的 `LinkedList`
- **循环链表**：约瑟夫问题、时间片轮转调度
