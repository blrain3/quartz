#数组

**数组（Array）** 就是把一堆相同类型的数据，按顺序放在一段连续的内存里。取的时候直接通过下标算地址，一秒定位。

> 数组是最基础、最常用的数据结构，几乎所有编程语言都原生支持。

### 数组的核心特性

- **连续内存**：元素在内存中一个挨着一个存放
- **随机访问**：通过索引 $O(1)$ 时间访问任意元素
- **固定大小**：静态数组一旦创建大小不可变（动态数组如 Java 的 `ArrayList` 底层仍是数组扩容）

### 数组的基本操作

| 操作 | 代码示例 | 时间复杂度 |
|:---|:--------|:---------|
| **随机访问** | `arr[i]` | $O(1)$ |
| **插入**（中间） | 需移动后续元素 | $O(n)$ |
| **删除**（中间） | 需移动后续元素 | $O(n)$ |
| **末尾插入** | 使用额外指针追踪 | $O(1)$* |
| **查找**（遍历） | 需要扫描 | $O(n)$ |

- 访问快，插入/删除慢（需要移动大量元素）

### 代码实现

#### Java

```java
/* 静态数组 */
int[] arr = new int[5];
arr[0] = 1;
arr[1] = 2;

/* 动态数组（ArrayList）底层也是数组 */
ArrayList<Integer> list = new ArrayList<>();
list.add(1);      // 末尾追加
list.add(0, 2);   // 指定位置插入（需要移动）
list.remove(0);   // 删除（需要移动）
```

#### C++

```cpp
/* 静态数组 */
int arr[5] = {1, 2, 3, 4, 5};

/* 动态数组 */
vector<int> vec = {1, 2, 3};
vec.push_back(4);               // 末尾追加
vec.insert(vec.begin(), 0);     // 头部插入
vec.erase(vec.begin() + 2);     // 删除第 2 个
```

#### Python

```python
# Python 的 list 是动态数组
arr = [1, 2, 3]
arr.append(4)        # 末尾追加
arr.insert(0, 0)     # 头部插入
arr.pop(2)           # 删除索引 2

# 静态数组（使用 array 模块）
import array
arr = array.array('i', [1, 2, 3])  # 'i' 表示 int 类型
```

### 数组对比链表

| 对比维度 | 数组 | 链表 |
|:--------|:----|:----|
| 内存分配 | 连续空间 | 分散空间（通过指针连接） |
| 随机访问 | $O(1)$ | $O(n)$ |
| 插入/删除 | $O(n)$（需移动） | $O(1)$（已知位置） |
| 缓存局部性 | ✅ 友好 | ❌ 不友好 |
| 空间开销 | 小（只存数据） | 大（额外存指针） |

### 应用场景

- 需要**频繁随机访问**的场景（如查表）
- **缓存友好**的数据处理（顺序遍历性能高）
- 作为栈、队列、哈希表等数据结构的底层实现
