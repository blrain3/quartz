#栈

**栈（Stack）** 就是一个后进先出的结构——只能从一头往里放东西，也只能从同一头往外拿。像一摞盘子，后放的先拿。

栈的特殊性体现在两个方面：
> 1. 元素只能从同一端进入和出去，这一端称为"**栈顶**"，另一端称为"**栈底**"。
> 2. 栈中元素必须遵循"**后进先出（LIFO, Last In First Out）**"的原则——最后入栈的元素最先出栈。

可以把栈想象成一摞盘子：你每次只能拿走最上面的盘子，放也只能放在最上面。

> ![堆栈数据结构](https://upload.wikimedia.org/wikipedia/commons/2/29/Data_stack.svg)

### 栈的基本操作

| 操作 | 描述 | 时间复杂度 |
|:---|:----|:---------|
| `push(x)` | 将元素 x 压入栈顶 | $O(1)$ |
| `pop()` | 弹出栈顶元素 | $O(1)$ |
| `peek()` / `top()` | 获取栈顶元素（不弹出） | $O(1)$ |
| `isEmpty()` | 判断栈是否为空 | $O(1)$ |
| `size()` | 返回栈中元素个数 | $O(1)$ |

所有操作都是 $O(1)$，这是栈最大的优点。

### 代码实现

#### Java

```java
// 使用 Stack 类（线程安全）
Stack<Integer> stack = new Stack<>();
stack.push(1);        // 入栈
stack.push(2);
int top = stack.pop(); // 出栈 → 2
int peek = stack.peek(); // 查看栈顶 → 1
boolean empty = stack.isEmpty();

// 推荐使用 Deque（更高效）
Deque<Integer> deque = new ArrayDeque<>();
deque.push(1);
deque.push(2);
int top2 = deque.pop();
```

#### C++

```cpp
#include <stack>
stack<int> st;
st.push(1);
st.push(2);
int top = st.top();   // 获取栈顶
st.pop();             // 弹出栈顶（不返回值）
bool empty = st.empty();
int size = st.size();
```

#### Python

```python
# 使用 list 模拟栈
stack = []
stack.append(1)    # 入栈
stack.append(2)
top = stack.pop()  # 出栈 → 2
peek = stack[-1]   # 查看栈顶 → 1
empty = len(stack) == 0
```

### 栈的两种实现方式

| 实现方式 | 优点 | 缺点 |
|:--------|:----|:----|
| **顺序栈（数组）** | 缓存友好、随机访问快 | 需要预分配空间，扩容时有开销 |
| **链栈（链表）** | 动态扩容、无空间浪费 | 额外指针空间、缓存不友好 |

### 栈的经典应用

1. **函数调用栈**：程序中的函数调用和返回就是靠栈实现的
2. **浏览器后退**：访问的页面依次入栈，点击后退时弹出
3. **括号匹配**：`{[()]}` 检查括号是否成对匹配
4. **表达式求值**：中缀转后缀表达式
5. **撤销操作（Undo）**：编辑器中的 Ctrl+Z
