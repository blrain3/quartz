**查找（Searching）** 是在数据集合中寻找特定元素的过程。根据数据是否有序、存储方式不同，有多种查找算法。

### 顺序查找（Linear Search）

逐一比较，直到找到目标或遍历完所有元素。适用于无序数据，时间复杂度 $O(n)$。

```java
int linearSearch(int[] arr, int target) {
    for (int i = 0; i < arr.length; i++) {
        if (arr[i] == target) return i;
    }
    return -1;
}
```

### 二分查找（Binary Search）

前提：数组**已有序**。每次取中间值比较，排除一半数据，复杂度 $O(\log n)$。

### 对比

| 算法 | 前提 | 时间复杂度 | 适用场景 |
|:----|:----|:----------|:--------|
| 顺序查找 | 无 | $O(n)$ | 小规模、无序数据 |
| 二分查找 | 有序 | $O(\log n)$ | 大规模静态数据 |
