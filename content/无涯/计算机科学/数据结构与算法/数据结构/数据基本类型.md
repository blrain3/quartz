**基本数据类型是 CPU 可以直接拿来运算的类型**，算法里天天都在用。常见的有这么几种：
- 整数类型 `byte`、`short`、`int`、`long`
- 浮点数类型 `float`、`double`，用来表示小数
- 字符类型 `char`，字母、标点、表情符号都算
- 布尔类型 `bool`，就是"是"和"否"

这些东西在计算机里都是二进制存的，一个二进制位就是 1 比特，8 个比特凑成 1 字节。

**Java 的基本数据类型**

| 类型  | 符号       | 占用空间 | 最小值 | 最大值 | 默认值   |
| --- | -------- | ---- | --- | --- | ----- |
| 整数  | `byte`   | 1 字节 |     |     | 0     |
|     | `short`  | 2 字节 |     |     | 0     |
|     | `int`    | 4 字节 |     |     | 0     |
|     | `long`   | 8 字节 |     |     | 0     |
| 浮点数 | `float`  | 4 字节 |     |     | 0.0f  |
|     | `double` | 8 字节 |     |     | 0.0   |
| 字符  | `char`   | 2 字节 |     |     | 0     |
| 布尔  | `bool`   | 1 字节 |     |     | false |


<center>数据类型分类总表</center>

|类型大类|子类型|说明|示例（C / Java / Python）|特点|
|---|---|---|---|---|
|数值类型 (Numeric)|整数 (int)|表示整数|`int a = 10;`|精确表示，无小数|
||浮点数 (float/double)|表示带小数的数|`float x = 3.14;`|有精度误差|
||复数 (complex)|实部 + 虚部|`z = 1+2j`（Python）|科学计算常用|
|字符串类型 (String)|字符数组|字符组成的数组|`char s[] = "hi";`|C 风格字符串|
||字符串对象|高级封装字符串|`String s = "hi";`|更安全易用|
|布尔类型 (Boolean)|布尔值|true / false|`bool flag = true;`|用于逻辑判断|
|数组类型 (Array)|一维/多维数组|同类型元素集合|`int arr[3] = {1,2,3};`|连续内存|
|指针类型 (Pointer)|地址变量|存储内存地址|`int *p = &a;`|可直接操作内存（C/C++）|
|结构体 (Struct)|自定义结构|多种类型组合|`struct S {int a;}`|类似“简易类”|
|枚举类型 (Enum)|常量集合|一组离散值|`enum Color {RED};`|提高可读性|
|共用体 (Union)|共享内存|多类型共用一块内存|`union U {int a; float b;}`|节省空间|
|函数指针|函数地址|指向函数|`int (*f)(int);`|可实现回调|
基本数据类型告诉你"存的是什么内容"，数据结构则告诉你"内容怎么组织"。两者搭配着用。
