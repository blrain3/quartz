#动态规划

### 什么是动态规划

**动态规划（Dynamic Programming，简称 DP）** 就是把复杂问题拆成小问题，算过的结果存下来，下次遇到直接拿，不用再算一遍。

> 核心思想：**记住已经算过的结果，下次直接用，不再重复计算。**

### DP 的三大要素

| 要素 | 含义 | 类比 |
|:---|:----|:----|
| **最优子结构** | 原问题的最优解由子问题的最优解推导而来 | 知道全校最好成绩 → 各班最好成绩 |
| **重叠子问题** | 不同子问题会重复出现 | 斐波那契中反复计算 F(3)、F(4) |
| **状态转移方程** | 描述子问题之间关系的公式 | 递推公式 |

### DP 的两种实现方式

#### 1. 自顶向下（记忆化搜索）

```text
从原问题出发，递归求解 → 遇到子问题先查表 → 没算过就算并存入备忘录
```

- 思路直观，从大问题往下拆
- 使用递归 + 缓存（memoization）
- 优点：只计算需要的子问题
- 缺点：递归有栈开销

#### 2. 自底向上（递推/填表）

```text
从最小的子问题开始算起，逐步向上推导，最终得到原问题的解
```

- 使用循环 + DP 表
- 优点：无递归开销，通常更快
- 缺点：有时需要计算所有子问题

| 对比 | 自顶向下（记忆化） | 自底向上（递推） |
|:---|:---------------|:-------------|
| 实现 | 递归 + 备忘录 | 循环 + 表格 |
| 性能 | 有递归开销 | 通常更快 |
| 计算量 | 只算需要的 | 通常算全部 |
| 代码 | 容易写 | 需要找递推顺序 |

### 经典问题一：斐波那契数列

$$
F(n) = F(n-1) + F(n-2),\quad F(1)=1,\;F(0)=0
$$

#### 普通递归（指数级，大量重复计算）
```java
int fib(int n) {
    if (n <= 1) return n;
    return fib(n-1) + fib(n-2);  // 大量重复计算！
}
```
- 时间复杂度：$O(2^n)$
- 问题：大量重复计算，F(3) 在计算 F(5) 和 F(4) 时各算一次

#### DP 自顶向下（记忆化）
```java
int fib(int n, int[] memo) {
    if (n <= 1) return n;
    if (memo[n] != 0) return memo[n];     // 直接返回已算过的结果
    memo[n] = fib(n-1, memo) + fib(n-2, memo);
    return memo[n];
}
```
- 时间复杂度：$O(n)$
- 空间复杂度：$O(n)$

#### DP 自底向上
```java
int fib(int n) {
    if (n <= 1) return n;
    int[] dp = new int[n + 1];
    dp[0] = 0;  // 初始状态
    dp[1] = 1;
    for (int i = 2; i <= n; i++)
        dp[i] = dp[i - 1] + dp[i - 2];  // 状态转移
    return dp[n];
}
```
- 时间复杂度：$O(n)$
- 空间复杂度：$O(n)$（可优化到 $O(1)$）

### 经典问题二：爬楼梯

> 每次可以爬 1 级或 2 级台阶，爬到第 $n$ 级有多少种不同方法？

**状态定义**：`dp[i]` = 爬到第 $i$ 级的方法数

**状态转移**：`dp[i] = dp[i-1] + dp[i-2]`  
（到第 i 级可以从 i-1 跨 1 步，或从 i-2 跨 2 步）

```java
int climbStairs(int n) {
    if (n <= 2) return n;
    int a = 1, b = 2;  // dp[1], dp[2]
    for (int i = 3; i <= n; i++) {
        int c = a + b;  // dp[i] = dp[i-1] + dp[i-2]
        a = b;
        b = c;
    }
    return b;
}
```
- 时间复杂度：$O(n)$，空间复杂度：$O(1)$

### 经典问题三：0-1 背包问题

> 给定 $n$ 个物品，每个物品有重量 $w_i$ 和价值 $v_i$。背包容量为 $C$，如何选择物品使总价值最大？

**状态定义**：`dp[i][j]` = 前 $i$ 个物品中选，容量为 $j$ 时的最大价值

**状态转移**：
```
dp[i][j] = max(dp[i-1][j], dp[i-1][j-w_i] + v_i)  若 j ≥ w_i
dp[i][j] = dp[i-1][j]                                若 j < w_i
```
（不选第 i 个 vs 选第 i 个，取较大值）

```java
int knapsack(int[] w, int[] v, int C) {
    int n = w.length;
    int[][] dp = new int[n + 1][C + 1];
    for (int i = 1; i <= n; i++) {
        for (int j = 0; j <= C; j++) {
            if (j < w[i-1])
                dp[i][j] = dp[i-1][j];           // 容量不够，不选
            else
                dp[i][j] = Math.max(dp[i-1][j],
                                    dp[i-1][j - w[i-1]] + v[i-1]);  // 选与不选取最大
        }
    }
    return dp[n][C];
}
```
- 时间复杂度：$O(n \times C)$
- 空间复杂度：$O(n \times C)$（可优化到 $O(C)$）

### 如何识别 DP 问题

1. **求最值**：最大、最小、最长、最短 → 很可能是 DP
2. **计数问题**：有多少种方法、多少条路径 → 可能是 DP
3. **有无后效性**：当前决策只影响未来，不影响过去 → DP 适用
4. **能否拆分子问题**：大问题能否用更小的同类问题描述 → DP 的核心

---

### DP 解题四步法

| 步骤 | 要做什么 | 例子（爬楼梯） |
|:---|:--------|:------------|
| **① 定义状态** | `dp[i]` 表示什么？ | `dp[i]` = 爬到第 i 级的方法数 |
| **② 找状态转移方程** | `dp[i]` 怎么从之前的状态来？ | `dp[i] = dp[i-1] + dp[i-2]` |
| **③ 确定初始条件** | 最小子问题的解是什么？ | `dp[1]=1, dp[2]=2` |
| **④ 确定遍历顺序** | 从小到大还是从大到小？ | 从小到大递推 i=3..n |

### 常见 DP 题型

| 类型 | 典型问题 | 状态定义 |
|:---|:--------|:--------|
| **线性 DP** | 爬楼梯、最大子数组和 | `dp[i]` 以 i 结尾 |
| **区间 DP** | 矩阵链乘、回文子串 | `dp[i][j]` 区间 [i, j] |
| **背包 DP** | 0-1 背包、完全背包 | `dp[i][j]` 前 i 个物品容量 j |
| **树形 DP** | 二叉树最大路径、打家劫舍 III | `dp[node]` 以 node 为根的树 |
| **状态压缩 DP** | 旅行商问题（TSP） | 用二进制位表示状态 |
