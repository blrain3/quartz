#贪心算法

### 什么是贪心

**贪心算法（Greedy Algorithm）** 的思路很直接：每一步都选当前看起来最好的，希望最后累积起来的结果也是全局最优的。

> 核心思想：**走一步看一步，选眼前最好的。**

### 贪心的三要素

| 要素 | 含义 |
|:----|:----|
| **贪心选择性质** | 可以通过局部最优选择来构造全局最优解 |
| **最优子结构** | 原问题的最优解包含子问题的最优解 |
| **无后效性** | 当前选择不会影响后面的选择（与 DP 不同） |

> 注意：**不是所有问题都能用贪心！** 必须证明贪心策略是正确的情况下才能使用。

### 经典问题一：找零问题

> 假设有 1 元、5 元、10 元、50 元、100 元的纸币，用最少的纸币凑出指定的金额。

**贪心策略**：每次选面额最大的纸币

```java
int coinChange(int[] coins, int amount) {
    // coins 已按从大到小排序
    int count = 0;
    for (int coin : coins) {
        count += amount / coin;   // 能用多少张就用多少张
        amount %= coin;
    }
    return count;
}
```

> ⚠️ 这个贪心成立的前提是**面额满足倍数关系**（如人民币）。如果面额是 [1, 3, 4]，贪心就会出错（凑 6 时贪心选 4+1+1=3 张，最优是 3+3=2 张）。这种情况下需要用 DP。

### 经典问题二：活动选择

> 给定一系列活动的开始和结束时间，选择尽可能多的互不重叠的活动。

**贪心策略**：每次选**结束时间最早**的活动

```java
int activitySelection(int[][] activities) {
    // 按结束时间排序
    Arrays.sort(activities, (a, b) -> a[1] - b[1]);

    int count = 1;
    int lastEnd = activities[0][1];  // 上一个选中活动的结束时间

    for (int i = 1; i < activities.length; i++) {
        if (activities[i][0] >= lastEnd) {  // 不重叠
            count++;
            lastEnd = activities[i][1];
        }
    }
    return count;
}
```

### 经典问题三：哈夫曼编码

> 给定字符及其出现频率，构造一棵二叉树使得编码总长度最短。

**贪心策略**：每次合并频率最小的两个节点

```java
// 使用优先队列（最小堆）
int huffmanCoding(int[] frequencies) {
    PriorityQueue<Integer> pq = new PriorityQueue<>();
    for (int f : frequencies) pq.offer(f);

    int totalCost = 0;
    while (pq.size() > 1) {
        int a = pq.poll();    // 最小的
        int b = pq.poll();    // 第二小的
        int sum = a + b;
        totalCost += sum;     // 合并代价
        pq.offer(sum);        // 放回堆中
    }
    return totalCost;
}
```

### 贪心 vs 动态规划

| 对比 | 贪心 | 动态规划 |
|:----|:----|:--------|
| **决策方式** | 只选当前最优，不考虑未来 | 综合考虑所有可能，取全局最优 |
| **子问题** | 每个阶段只做一个选择 | 每个阶段考虑所有选择 |
| **适用条件** | 贪心选择性质 + 最优子结构 | 最优子结构 + 重叠子问题 |
| **效率** | 通常 $O(n)$ 或 $O(n \log n)$ | 通常 $O(n)$ ~ $O(n^3)$ |
| **证明难度** | 需要证明贪心的正确性 | 状态转移方程写出来就是对的 |
| **典型问题** | 活动选择、哈夫曼编码 | 背包、编辑距离、最短路径 |

### 常见贪心问题

| 问题 | 贪心策略 | 复杂度 |
|:----|:--------|:------|
| 找零（标准面额） | 用最大面额 | $O(n)$ |
| 活动选择 | 选结束最早的 | $O(n \log n)$ |
| 哈夫曼编码 | 合并最小的两个 | $O(n \log n)$ |
| 最小生成树（Prim） | 选最近节点 | $O(E \log V)$ |
| 最小生成树（Kruskal） | 选最小边 | $O(E \log E)$ |
| Dijkstra 最短路 | 选当前最近节点 | $O(E \log V)$ |
| 区间调度 | 按结束时间排序选 | $O(n \log n)$ |

### 如何判断一个问题是否能用贪心

1. 问自己：**当前这一步选最优，会不会影响后续选择？**
2. 如果会 → 大概率不是贪心（可能是 DP）
3. 如果不会 → 有可能是贪心（但仍需证明）
