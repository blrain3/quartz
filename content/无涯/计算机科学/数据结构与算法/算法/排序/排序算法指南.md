## 一、复杂度速查表

|  算法  |         平均         |      最坏      |      最好      |     空间     |   稳定性   |
| :--: | :----------------: | :----------: | :----------: | :--------: | :-----: |
| 冒泡排序 |      $O(n²)$       |   $O(n²)$    |  **$O(n)$**  |   $O(1)$   | &#10003 |
| 选择排序 |      $O(n²)$       |   $O(n²)$    |   $O(n²)$    |   $O(1)$   | &#10007 |
| 插入排序 |      $O(n²)$       |   $O(n²)$    |  **$O(n)$**  |   $O(1)$   | &#10003 |
| 希尔排序 |    $O(n^{1.3})$    |   $O(n²)$    |    $O(n)$    |   $O(1)$   | &#10007 |
| 归并排序 | **$O(n\,log\,n)$** | $O(n log n)$ | $O(n log n)$ |   $O(n)$   | &#10003 |
| 快速排序 | **$O(n\,log\,n)$** |   $O(n²)$    | $O(n log n)$ | $O(log n)$ | &#10007 |
| 堆排序  | **$O(n\,log\,n)$** | $O(n log n)$ | $O(n log n)$ |   $O(1)$   | &#10007 |
| 计数排序 |    **$O(n+k)$**    |  $O(n + k)$  |  $O(n + k)$  |   $O(k)$   | &#10003 |
| 桶排序  |     $O(n + k)$     |   $O(n²)$    |  $O(n + k)$  | $O(n + k)$ | &#10003 |
| 基数排序 |     $O(n × k)$     |  $O(n × k)$  |  $O(n × k)$  | $O(n + k)$ | &#10003 |

> **$k$** = 桶数量 / 数字位数

## 二、总结

| 算法 | 核心特点 |
|:---|:---|
| **冒泡排序** | 最简单，已有序时最优 O(n) |
| **选择排序** | 不稳定但交换次数最少 n-1 次 |
| **插入排序** | 扑克牌思想，基本有序时效率高 |
| **[[希尔排序]]** | 插入排序的改进版，使用增量序列 |
| **归并排序** | 稳定！分治合并，最坏也是 O(n log n) |
| **快速排序** | 最常用！实际最快，但最坏 O(n²) |
| **堆排序** | 最坏稳定 O(n log n)，原地 O(1) 空间 |
| **计数排序** | 整数专属，线性 O(n) 但需额外空间 |
| **桶排序** | 分桶 + 桶内排序，适合均匀分布数据 |
| **基数排序** | 按位排序，适合整数/固定格式数据 |

## 三、算法选择决策树

```
数据规模？
├── 极小（n < 50）
│   └── → 插入排序（常数小，最实用）
│
├── 中等（50 < n < 10000）
│   ├── 需稳定排序 → 归并排序
│   └── 追求速度 → 快速排序
│
└── 大数据（n > 10000）
    ├── 整数 / 范围有限 → 计数排序 / 基数排序
    ├── 需稳定最坏 O(n log n) → 堆排序
    └── 通用场景 → 快速排序（实际最快）
```

## 四、应用场景

| 场景 | 推荐算法 | 原因 |
|:---|:---|:---|
| 教学演示 | 冒泡排序 | 简单直观 |
| 基本有序数据 | 插入排序 | 接近 O(n) |
| 通用快速排序 | 快速排序 | 实际最快 |
| 必须稳定排序 | 归并排序 | 完全稳定 |
| 内存受限 | 堆排序 | O(1) 空间 |
| Top-K 问题 | 堆排序 | 建堆 O(n) |
| 整数线性排序 | 计数排序 | O(n) 时间 |
| 外部排序 | 归并排序 | 顺序读写友好 |
| 浮点数排序 | 桶排序 | 可均分布 |

## 五、面试要点

### 1️⃣ 稳定排序有哪些？
> **冒泡、插入、归并、计数、桶、基数**

### 2️⃣ 原地排序有哪些？
> **冒泡、选择、插入、希尔、快排、堆排**

### 3️⃣ 哪些排序时间恒定 O(n log n)？
> **归并、堆排**（快排最坏 O(n²)）

### 4️⃣ 空间 O(1) 的排序？
> **冒泡、选择、插入、希尔、堆排**

### 5️⃣ 最快的是哪个？
> - **理论**：归并/堆排（最坏稳定 O(n log n)）
> - **实际**：快速排序（常数因子最小）

## 六、快排优化

| 优化策略 | 说明 |
|:---|:---|
| 随机基准 | 避免最坏情况 |
| 三数取中 | 取首/中/尾的中位数作为基准 |
| 小区间用插入 | n < 10 时切换到插入排序 |
| 尾递归优化 | 减少递归深度 |
