**冒泡排序（bubble sort）** 通过连续比较相邻元素并交换顺序错误的元素来完成排序。每轮遍历将当前未排序部分的最大元素"冒泡"到最右端，重复 n-1 轮后数组有序。
[![File:Bubble-sort.gif](https://upload.wikimedia.org/wikipedia/commons/0/06/Bubble-sort.gif?_=20110418154649)](https://upload.wikimedia.org/wikipedia/commons/0/06/Bubble-sort.gif)

##  算法流程

![冒泡排序流程](https://www.hello-algo.com/chapter_sorting/bubble_sort.assets/bubble_sort_overview.png)

>**像气泡一样，大的元素不断"浮"到右边，最终完成排序。**

java
```java
void bubbleSort(int[] nums) {
    // 外循环：未排序区间 [0, i]
    for (int i = nums.length - 1; i > 0; i--) {
        // 内循环：将最大值交换到 i 位置
        for (int j = 0; j < i; j++) {
            if (nums[j] > nums[j + 1]) {
                // 交换
                int tmp = nums[j];
                nums[j] = nums[j + 1];
                nums[j + 1] = tmp;
            }
        }
    }
}
```

  
## 优化（提前结束）
如果某轮没有任何交换，说明已经有序，直接退出。
```java
void bubbleSortWithFlag(int[] nums) {
    for (int i = nums.length - 1; i > 0; i--) {
        boolean flag = false;  // 标志位
        for (int j = 0; j < i; j++) {
            if (nums[j] > nums[j + 1]) {
                int tmp = nums[j];
                nums[j] = nums[j + 1];
                nums[j + 1] = tmp;
                flag = true;  // 发生了交换
            }
        }
        if (!flag) break;  // 没交换，已有序，退出
    }
}
```

  
## 算法特性

| 特性    | 说明                         |
| ----- | -------------------------- |
| 时间复杂度 | 最坏/平均 O(n²)，优化后有序数组可达 O(n) |
| 空间复杂度 | O(1)，原地排序                  |
| 稳定性   | 是 稳定（相等元素不交换）              |
- **时间复杂度为 、自适应排序**：各轮“冒泡”遍历的数组长度依次为 、、、、 ，总和为  。在引入 `flag` 优化后，最佳时间复杂度可达到  。
- **空间复杂度为 、原地排序**：指针  和  使用常数大小的额外空间。
- **稳定排序**：由于在“冒泡”中遇到相等元素不交换。
