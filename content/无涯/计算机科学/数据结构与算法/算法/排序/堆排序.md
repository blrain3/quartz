**堆排序（heap sort）** 靠堆这种数据结构来排。先建一个最大堆，然后不断把堆顶元素（最大的那个）取出来放到末尾，剩下的元素重新调整成堆，循环到取完为止。

![](https://upload.wikimedia.org/wikipedia/commons/f/fe/Heap_sort_example.gif)

## 算法流程

堆排序分为两个阶段：

### 阶段一：建堆
将原数组构建为一个**大顶堆**（用于升序排序）。从最后一个非叶子节点开始，自底向上执行 `siftDown` 操作。

### 阶段二：排序
1. 将堆顶元素（最大值）与堆的最后一个元素交换
2. 堆长度减 1（将已排序元素从堆中移除）
3. 对新的堆顶执行 `siftDown`，恢复堆性质
4. 重复以上步骤，直到堆为空

### 核心操作：siftDown（下滤）
```java
void siftDown(int[] nums, int n, int i) {
    // n 为堆的长度，i 为当前节点
    while (true) {
        int l = 2 * i + 1;
        int r = 2 * i + 2;
        int ma = i;
        if (l < n && nums[l] > nums[ma]) ma = l;
        if (r < n && nums[r] > nums[ma]) ma = r;
        if (ma == i) break;  // 当前节点已是最大
        swap(nums, i, ma);
        i = ma;  // 继续向下调整
    }
}
```

## 代码实现

### Java
```java
void siftDown(int[] nums, int n, int i) {
    while (true) {
        int l = 2 * i + 1;
        int r = 2 * i + 2;
        int ma = i;
        if (l < n && nums[l] > nums[ma]) ma = l;
        if (r < n && nums[r] > nums[ma]) ma = r;
        if (ma == i) break;
        int tmp = nums[i];
        nums[i] = nums[ma];
        nums[ma] = tmp;
        i = ma;
    }
}

void heapSort(int[] nums) {
    // 1. 建堆：从最后一个非叶子节点开始，自底向上下滤
    for (int i = nums.length / 2 - 1; i >= 0; i--)
        siftDown(nums, nums.length, i);
    // 2. 排序：不断取出堆顶
    for (int i = nums.length - 1; i > 0; i--) {
        int tmp = nums[0];
        nums[0] = nums[i];
        nums[i] = tmp;
        siftDown(nums, i, 0);
    }
}
```

### C++
```cpp
void siftDown(vector<int>& nums, int n, int i) {
    while (true) {
        int l = 2 * i + 1;
        int r = 2 * i + 2;
        int ma = i;
        if (l < n && nums[l] > nums[ma]) ma = l;
        if (r < n && nums[r] > nums[ma]) ma = r;
        if (ma == i) break;
        swap(nums[i], nums[ma]);
        i = ma;
    }
}

void heapSort(vector<int>& nums) {
    for (int i = nums.size() / 2 - 1; i >= 0; i--)
        siftDown(nums, nums.size(), i);
    for (int i = nums.size() - 1; i > 0; i--) {
        swap(nums[0], nums[i]);
        siftDown(nums, i, 0);
    }
}
```

## 算法特性

| 特性 | 说明 |
|:---|:---|
| 时间复杂度 | 最好/平均/最坏均为 $O(n \log n)$ |
| 空间复杂度 | $O(1)$，原地排序 |
| 稳定性 | ❌ 不稳定（交换可能改变相等元素的相对顺序） |
| 排序方式 | 原地排序 |
| 自适应 | ❌ 非自适应（任何输入都需要完整建堆 + 排序） |

## 优势与不足

### 优势
- **最坏情况也是 $O(n \log n)$**，比快排（最坏 $O(n^2)$）更可靠
- **原地排序 $O(1)$ 空间**，比归并排序节省内存
- 适合 **Top-K 问题**：建堆 $O(n)$，取 K 个元素只需 $O(K \log n)$

### 不足
- 不稳定排序
- **常数因子较大**（下滤操作涉及多次比较和交换），实际速度慢于快排
- **缓存不友好**：堆元素在内存中跳转访问，局部性差
- 不适用于小规模数据

## 应用场景

- **Top-K 问题**：在海量数据中找最大/最小的 K 个元素
- **优先级队列**的底层实现
- **内存受限**且需要稳定 $O(n \log n)$ 的场景
