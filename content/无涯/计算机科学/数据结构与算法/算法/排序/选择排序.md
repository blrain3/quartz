**选择排序（selection sort）** 每轮从未排序区间选取最小元素，将其放到已排序区间的末尾。重复 n-1 轮后，整个数组即有序。
[![文件：选择排序动画.gif](https://upload.wikimedia.org/wikipedia/commons/9/94/Selection-Sort-Animation.gif)](https://upload.wikimedia.org/wikipedia/commons/9/94/Selection-Sort-Animation.gif)

#### Java实现
```java
/* 选择排序 */
void selectionSort(int[] nums) {
    int n = nums.length;
    // 外循环：未排序区间为 [i, n-1]
    for (int i = 0; i < n - 1; i++) {
        // 内循环：找到未排序区间内的最小元素
        int k = i;
        for (int j = i + 1; j < n; j++) {
            if (nums[j] < nums[k])
                k = j; // 记录最小元素的索引
        }
        // 将该最小元素与未排序区间的首个元素交换
        int temp = nums[i];
        nums[i] = nums[k];
        nums[k] = temp;
    }
}
```

#### C++实现
```cpp
/* 选择排序 */
void selectionSort(vector<int> &nums) {
    int n = nums.size();
    // 外循环：未排序区间为 [i, n-1]
    for (int i = 0; i < n - 1; i++) {
        // 内循环：找到未排序区间内的最小元素
        int k = i;
        for (int j = i + 1; j < n; j++) {
            if (nums[j] < nums[k])
                k = j; // 记录最小元素的索引
        }
        // 将该最小元素与未排序区间的首个元素交换
        swap(nums[i], nums[k]);
    }
}
```

#### Python实现
```python
def selection_sort(nums: list[int]):
    """选择排序"""
    n = len(nums)
    # 外循环：未排序区间为 [i, n-1]
    for i in range(n - 1):
        # 内循环：找到未排序区间内的最小元素
        k = i
        for j in range(i + 1, n):
            if nums[j] < nums[k]:
                k = j  # 记录最小元素的索引
        # 将该最小元素与未排序区间的首个元素交换
        nums[i], nums[k] = nums[k], nums[i]
```

## 算法特性

| 特性 | 说明 |
|:---|:---|
| 时间复杂度 | 最好/平均/最坏均为 $O(n^2)$，**非自适应** |
| 空间复杂度 | $O(1)$，原地排序 |
| 稳定性 | 否 不稳定（元素交换可能打乱相等元素的相对顺序） |
| 排序方式 | 原地排序 |
| 自适应 | 否 非自适应（无论输入是否有序，每轮都要完整遍历）|

## 与其他 $O(n^2)$ 排序的对比

| 对比维度 | 选择排序 | 冒泡排序 | 插入排序 |
|:--------|:--------|:--------|:--------|
| 自适应 | 否 始终 $O(n^2)$ | 是 有序时 $O(n)$ | 是 有序时 $O(n)$ |
| 稳定性 | 否 不稳定 | 是 稳定 | 是 稳定 |
| 交换次数 | 最少（$n-1$ 次） | 最多（$n^2/2$ 次） | 适中（赋值操作） |
| 实际速度 | 最慢 | 中等 | 最快 |

### 选择排序的独特优势
- **交换次数最少**：无论数据如何，只交换 $n-1$ 次
- 当交换操作成本极高时（如交换的是大型对象），选择排序可能是最优选择
