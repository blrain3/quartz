**计数排序（counting sort）** 不靠比大小来排，而是靠数数。它统计每个数值出现了几次，然后按顺序把这些数倒出来，自然就排好了。只适用于整数数组。

![](https://upload.wikimedia.org/wikipedia/commons/d/d6/CountingSort.gif)

## 算法流程

以数组 `nums = [1, 0, 3, 1, 0, 1]` 为例：

1. **统计频率**：遍历数组，统计每个元素出现的次数，得到 `counter = [2, 3, 0, 1]`（元素 0 出现 2 次，1 出现 3 次，2 出现 0 次，3 出现 1 次）
2. **累加前缀和**：将 `counter` 转换为前缀和数组，`counter[i]` 表示 ≤ i 的元素个数。得到 `prefix = [2, 5, 5, 6]`
3. **反向填充结果**：从后向前遍历原数组，根据元素值查找前缀和，得到该元素在结果数组中的位置，随后将前缀和减 1

> 反向填充是为了保证**稳定性**。

## 代码实现

### Java
```java
void countingSort(int[] nums) {
    // 1. 获取数组的最大值（确定计数范围）
    int m = 0;
    for (int num : nums)
        if (num > m) m = num;

    // 2. 统计频率
    int[] counter = new int[m + 1];
    for (int num : nums)
        counter[num]++;

    // 3. 计算前缀和（counter[i] 表示 ≤ i 的元素个数）
    for (int i = 1; i <= m; i++)
        counter[i] += counter[i - 1];

    // 4. 反向遍历原数组，填充结果数组
    int n = nums.length;
    int[] res = new int[n];
    for (int i = n - 1; i >= 0; i--) {
        int num = nums[i];
        res[counter[num] - 1] = num;
        counter[num]--;
    }

    // 5. 将结果复制回原数组
    for (int i = 0; i < n; i++)
        nums[i] = res[i];
}
```

### C++
```cpp
void countingSort(vector<int>& nums) {
    int m = 0;
    for (int num : nums) m = max(m, num);

    vector<int> counter(m + 1, 0);
    for (int num : nums) counter[num]++;

    for (int i = 1; i <= m; i++)
        counter[i] += counter[i - 1];

    int n = nums.size();
    vector<int> res(n);
    for (int i = n - 1; i >= 0; i--) {
        int num = nums[i];
        res[counter[num] - 1] = num;
        counter[num]--;
    }

    nums = res;
}
```

### Python
```python
def counting_sort(nums: list[int]):
    """计数排序"""
    if not nums: return
    m = max(nums)

    counter = [0] * (m + 1)
    for num in nums:
        counter[num] += 1

    # 计算前缀和
    for i in range(1, m + 1):
        counter[i] += counter[i - 1]

    # 反向填充结果
    n = len(nums)
    res = [0] * n
    for i in range(n - 1, -1, -1):
        num = nums[i]
        res[counter[num] - 1] = num
        counter[num] -= 1

    # 复制回原数组
    for i in range(n):
        nums[i] = res[i]
```

## 算法特性

| 特性 | 说明 |
|:---|:---|
| 时间复杂度 | $O(n + k)$，其中 $k$ 是数据范围（最大值 - 最小值） |
| 空间复杂度 | $O(k)$，需要额外计数数组 |
| 稳定性 | ✅ 稳定（使用前缀和 + 反向遍历实现） |
| 排序方式 | 非原地排序 |
| 比较排序 | ❌ 非比较排序（基于统计，不比较元素大小） |

## 使用限制

- **只能排序整数**（或可以映射为整数的数据）
- 数据范围 $m$ 不能太大——如果 $m$ 远大于 $n$，空间浪费严重
- 只适用于**非负整数**（若包含负数，需要先平移）

## 应用场景

- **数据范围较小**的整数排序（如成绩、年龄、0-100 的分数）
- 作为 **基数排序** 的子过程（对每一位执行计数排序）
- 输入数据量 $n$ 较大但范围 $m$ 较小的情况
