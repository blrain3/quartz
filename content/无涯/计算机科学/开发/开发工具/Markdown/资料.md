## 资源

### 入门资源
- [Markdown Guide](https://www.markdownguide.org/)：免费开源参考指南。
- [John Gruber 的 Markdown 文档](https://daringfireball.net/projects/markdown/)：Markdown 创建者撰写的原始指南。
- [Markdown 教程](https://www.markdowntutorial.com/)：一个开源网站，可在网页浏览器中试用 Markdown。
- [超棒的 Markdown](https://github.com/mundimark/awesome-markdown)：Markdown 工具和学习资源列表。
- [Markdown 排版](https://dave.autonoma.ca/blog/2019/05/22/typesetting-markdown-part-1)：多部分系列文章，介绍使用 [pandoc](https://pandoc.org/) 和 [ConTeXt](https://www.contextgarden.net/) 排版 Markdown 文档的生态系统。

### Markdown 入门教程
- [手把手教会你使用 Markdown](https://blog.csdn.net/qq_40818172/article/details/126260661)
- [Markdown 教程](https://markdown.com.cn/basic-syntax/)
- [MARKDOWN 中文简介](https://www.markdown.cn/)
- [Markdown 教程](https://www.runoob.com/markdown/md-tutorial.html)（菜鸟教程）
