[API](https://en.wikipedia.org/wiki/API)（Application Programming Interface，应用程序编程接口） 是软件组件之间互相**通信**的“契约”和“窗口”——它规定了一个程序如何请求另一个程序提供的数据或功能，同时隐藏内部实现细节。

本质是程序与程序之间的服务窗口，类比如：你（客户端）→ 店员（API）→ 后厨（服务器），你无需知道制作过程，只需按规则点单。

>**API = 程序之间的服务员 + 安全窗口 + 功能拼装接口**  

---
## 工作流程

1. 客户端发送请求
2. 服务器处理
3. 服务器返回响应
>客户端 ↔ API ↔ 服务端

API在现代架构中扮演着十分重要的角色：
- **前后端分离的桥梁**：前端（React/Vue）通过 API 调用后端（Java/Node.js）
- **微服务互连基础**：大型系统拆分为多个服务，通过 API 相互调用
- **安全屏障**：防止前端直接操作数据库（`DROP TABLE` 等危险操作）

---
## 常见 API 类型与概念

| 概念              | 说明                                           |
| --------------- | -------------------------------------------- |
| **REST API**    | 最主流，用 HTTP 管理资源（GET/POST/PUT/DELETE）         |
| **Endpoint**    | API 的具体地址（如 `https://api.example.com/users`） |
| **JSON**        | 最常用的数据交换格式                                   |
| **API Key**     | 开发者身份凭证，用于鉴权和限流                              |
| **Token**       | 用户登录后的凭证（如 JWT）                              |
| **API Gateway** | 统一入口，负责鉴权、限流、路由、日志等                          |
