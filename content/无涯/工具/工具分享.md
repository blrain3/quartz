## 📦 系统增强

[HiBit Uninstaller](https://www.hibitsoft.ir/Uninstaller.html) — 强力卸载工具，可扫描残留文件和注册表。

[BCUninstaller](https://www.bcuninstaller.com/) — 批量卸载管理器，支持同时卸载多个程序。

[7-Zip](https://www.7-zip.org/) — 开源压缩解压工具，解压王者。

[TranslucentTB](https://translucenttb.net/) — 让 Windows 任务栏变透明/毛玻璃效果。

[Microsoft PowerToys](https://learn.microsoft.com/en-us/windows/powertoys/) — Windows 官方增强工具集（包含 FancyZones、PowerRename 等）。

[TrafficMonitor](https://trafficmonitor.org/) — 任务栏网速监控，实时显示上传下载速度。

[Process Lasso](https://bitsum.com/) — 进程优化工具，自动调整 CPU 优先级。

[EarTrumpet](https://eartrumpet.app/) — Windows 独立音量控制，给每个应用单独调音量。

[KeePass](https://keepass.info/) — 开源密码管理器，本地存储密码库。

[1Password](https://1password.com/) — 跨平台密码管理器，支持家庭共享。

[WizTree](https://diskanalyzer.com/) — 磁盘空间分析，秒级扫描大文件。

[AutoHotkey](https://www.autohotkey.com/) — Windows 自动化脚本工具，自定义快捷键和宏。

[HWiNFO](https://www.hwinfo.com/) — 硬件检测和监控工具，实时显示传感器数据。

[CrystalDiskMark](https://crystalmark.info/en/) — 磁盘读写速度测试工具，衡量 SSD/HDD 性能。

[GPU-Z](https://www.techpowerup.com/gpuz/) — 显卡详细信息和状态监控，显示 GPU 温度、频率等。

[CPU-Z](https://www.cpuid.com/softwares/cpu-z.html) — CPU、主板、内存详细信息检测工具。

[Office Tool Plus](https://www.officetool.plus/zh-cn/) — Office 部署工具，自定义安装和激活。

[WireGuard](https://www.wireguard.com/) — 现代 VPN 协议，简洁高效的内核级加密通信。
