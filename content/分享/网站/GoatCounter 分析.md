> [GoatCounter](https://www.goatcounter.com/)是一个开源的网络分析平台，提供免费的捐赠支持型托管服务或自托管应用程序。它旨在提供易于使用、有意义且注重隐私的网络分析。

### 开始

[GoatCounter 文档](https://www.goatcounter.com/help/start)

只需将以下 JavaScript 代码添加到页面上的任意位置即可：
```
<script data-goatcounter="https://MYCODE.goatcounter.com/count"        
async src="//gc.zgo.at/count.js">
</script>
```

### 实用设置

设置→网站设置→可嵌入 goatcounter 的网站

设置⇒管理页面浏览量

忽略 IP 地址，然后他们会提供一个按钮来抓取你的 IP 地址！

设置→站点→添加新站点。然后您可以将统计数据分配到不同的网页上。每个网页的设置都是独立的，因此请确保所有设置都正确无误。

### 设置完成后

嵌入后就可以看见网站分析数据了（最好关闭广告屏蔽器和并检查是否禁用网路跟踪）。

<img src="https://tg.salix.eu.org/file/1788879932419_image.webp" alt="image.webp" width=100% />

- 如果正在使用 GoatCounter，请确保在[内容安全策略](https://www.goatcounter.com/code/csp)中允许它。
- 如果看不到任何页面浏览量，很可能是浏览器的广告拦截器阻止了它。
- 请禁用广告拦截器并再次检查。
