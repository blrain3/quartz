title: 如何搭建图床
date: 2025-12-23

---
1. 选择对象存储服务，例如 Cloudflare R2、Amazon S3 或 Hugging Face，作为图片的实际存储位置。
2. 创建一个 Bucket，并配置访问权限和 CORS，确保图片能够正常通过 HTTP/HTTPS 访问。
3. 准备一个自己的域名，例如 `img.example.com`，将其解析到对象存储或 CDN，并通过 HTTPS 对外提供图片访问地址。
4. 搭建一个简单的后端 API，负责图片上传、文件类型校验、生成唯一文件名，并返回类似 `https://img.example.com/xxx.jpg` 的图片 URL。
5. 最终形成「前端上传 → API → 对象存储 → CDN/自定义域名 → 图片 URL」的完整图床架构。

推荐使用 [**CloudFlare-ImgBed**](https://github.com/MarSeventh/CloudFlare-ImgBed) 搭建上传服务，并配合 [Telegram](https://web.telegram.org/) 机器人实现便捷的图片上传与管理，将项目部署到 [Cloudflare](https://dash.cloudflare.com/) 相关服务上即可。

不过，追求稳定性的话，最好还是使用 S3 兼容的对象存储服务，例如 Cloudflare R2、Amazon S3 等。R2 可以与 Cloudflare CDN、Workers 和自定义域名进行深度集成；Hugging Face 也可以作为文件存储方案。

应用程序可以选择[PicGO](https://github.com/Molunerfinn/picgo)或者[PicList](https://github.com/Kuingsmile/piclist)，但是整体不如网页方便。
