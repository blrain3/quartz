我用启动器处理版本、Java 路径和 Mod 加载器。PCL2 是 Windows 启动器；这篇按我原有笔记整理操作入口，具体界面可能随版本变化。

## 下载

PCL2 官网提供启动器下载与项目说明。许可和分发方式应以当前项目页面为准；本文不把它概括成“开源”或免许可限制。

[PCL2 官网](https://pcl2.aoe.top/)

![PCL2 官网首页](https://tg.salix.eu.org/file/1789464236879_image.webp)

该版本的历史记录显示可解压后运行。不同 Windows 环境的权限、运行库和安全策略可能不同，便携不等于在任何电脑都无需配置。

![解压后的文件夹](https://tg.salix.eu.org/file/1789464409006_image.webp)

首次启动没有教程流程，进入主界面后就可以开始配置。

## 初始设置

Java 路径一般能自动检测到。如果你的系统装了多个 Java 版本，或者 PCL2 没找到，手动指定一下就行——Java 版本要按 Minecraft 版本及加载器要求选择；不要把 Java 8 和 Java 17 当作所有旧版/新版的完整分界表。

内存分配是另一个常见坑。给太多，系统本身会开始和 Minecraft 抢资源；给太少，游戏跑起来之后 Mod 一多就崩。内存需求随 Minecraft 版本、模组包、渲染距离和系统可用内存变化。先用整合包说明或启动日志给的建议值，再观察实际占用；不要因为机器内存更大就把分配值一味调高。本文没有同一硬件上的实测数据。

## 启动游戏

主界面左侧选版本，点启动。

![点击启动](https://tg.salix.eu.org/file/1789464530524_image.webp)

启动时如果出现命令行窗口，先看它是否由启动器用于显示日志；关闭窗口前确认游戏进程是否依赖它。界面行为可能随版本变化。

![启动中](https://tg.salix.eu.org/file/1789465185460_image.webp)

看到主菜单说明游戏已启动；模组、联机与运行稳定性仍需分别检查。左下角会显示版本号和 Mod 加载器信息。

![游戏主菜单](https://tg.salix.eu.org/file/1789465211568_image.webp)

## 安装 Mod 加载器

可在版本管理里为相应 Minecraft 版本安装兼容的加载器；菜单名称和支持范围可能随启动器版本变化。手动安装包或启动器自动安装都需要匹配 Minecraft 与加载器版本。

Forge、Fabric 等加载器需要匹配 Minecraft 版本；模组之间的兼容性仍须另查。

## 联机游戏

PCL2 在这里负责启动游戏。连接多人服务器仍走 Minecraft 的多人游戏功能；启动器本身不提供服务器，也不能把它和第三方联机房间功能混为一谈。

添加服务器：多人游戏 → 添加服务器 → 填地址。

![添加服务器](https://tg.salix.eu.org/file/1789464665954_image.webp)

选中后点“加入服务器”。

![连接服务器](https://tg.salix.eu.org/file/1789464840922_image.webp)

连上之后正常进游戏。

![进入游戏](https://tg.salix.eu.org/file/1789464829416_image.webp)

## 皮肤与皮肤库

Minecraft 默认皮肤选择有限。国内常用的皮肤站是 [LittleSkin](https://littleskin.cn/)，皮肤站的绑定方式取决于启动器、账号和服务器侧配置；使用前查看 LittleSkin 当前说明，不能仅凭此处保证所有服务器都显示。

## 局域网联机方案

如果和朋友不在同一个局域网下，有两种方案：

- **内网穿透**（如 frp、ngrok、樱花 frp）：把本地端口暴露到公网，朋友通过公网 IP 或域名连进来。适合临时联机，但延迟取决于双方网络质量。
- **虚拟局域网**（如 ZeroTail、Tailscale、Radmin VPN）：把多台机器拉到同一个虚拟局域网里，游戏直接走局域网模式。

选择内网穿透或虚拟局域网时，先考虑谁能访问、需要开放哪些端口以及服务端运行位置。延迟和稳定性取决于两端网络与具体服务，不能仅按工具类别保证高低。

## 常用服务器

### 国内服务器

- **简幻欢**（https://simpfun.cn/）：一个可查看的服务器服务选项；套餐、延迟和可用性需按自己的地区及当前服务核实。

### 国外服务器

- **Aternos**（https://aternos.org/servers/）：可查看其当前免费服务器条件和排队规则；功能与限制以服务方现行说明为准。
