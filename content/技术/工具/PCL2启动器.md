如果你长期玩 Minecraft，花在启动器上的时间不会少——换版本、装 Mod、调试 Java 路径、给朋友开房间，这些重复操作加起来的成本远超"选哪个启动器"本身。PCL2 的设计思路不是"功能最多"，而是"配一次就不用再管"。

## 下载

PCL2 是龙腾猫跃维护的开源启动器，官网首页长这样：

![PCL2 官网首页](https://tg.salix.eu.org/file/1789464236879_image.webp)

绿色免安装，解压即用。不需要注册表，不需要管理员权限，U 盘里放一份就能在任何 Windows 机器上跑起来。

![解压后的文件夹](https://tg.salix.eu.org/file/1789464409006_image.webp)

首次启动会走一遍引导流程，语言默认中文，不需要额外设置。

![首次启动引导](https://tg.salix.eu.org/file/1789464489873_image.webp)

## 初始设置

Java 路径一般能自动检测到。如果你的系统装了多个 Java 版本，或者 PCL2 没找到，手动指定一下就行——通常指向 Java 8（1.12 以下版本）或 Java 17（1.17+ 版本）。

内存分配是另一个常见坑。给太多，系统本身会开始和 Minecraft 抢资源；给太少，游戏跑起来之后 Mod 一多就崩。一个经验值：纯原版 2-4GB，轻量 Mod 包 4-6GB，大型整合包 6-8GB。如果你总内存只有 8GB，别超过 4GB；16GB 的机器可以放心给到 6-8GB。

## 启动游戏

主界面左侧选版本，点启动。

![点击启动](https://tg.salix.eu.org/file/1789464530524_image.webp)

启动中会弹一个命令行窗口，别关它——那是游戏进程本身。

![启动中](https://tg.salix.eu.org/file/1789465185460_image.webp)

进游戏看到主菜单就说明一切正常。左下角会显示版本号和 Mod 加载器信息。

![游戏主菜单](https://tg.salix.eu.org/file/1789465211568_image.webp)

## 安装 Mod 加载器

PCL2 内置了 Forge、Fabric、Quilt 等主流加载器的自动安装。流程是：版本列表 → 右键 → 安装 → 选加载器 → 等。不需要去对应官网手动下 installer，也不需要跑 Java 命令。

唯一需要注意的版本匹配问题：Forge 和 Fabric 都有"对应某个 Minecraft 版本"的概念，选错了装不上。PCL2 的下拉框里只会显示兼容的版本，这已经帮你避开了大多数坑。

## 联机游戏

PCL2 本身不依赖第三方联机工具（HMCL 那种内置的"联机房间"），走的是标准的 Minecraft 多人游戏协议。

添加服务器：多人游戏 → 添加服务器 → 填地址。

![添加服务器](https://tg.salix.eu.org/file/1789464665954_image.webp)

选中后点"加入服务器"。

![连接服务器](https://tg.salix.eu.org/file/1789464840922_image.webp)

连上之后正常进游戏。

![进入游戏](https://tg.salix.eu.org/file/1789464829416_image.webp)

## 为什么是 PCL2

说实话，启动器之间的功能差距没有想象中那么大——下载游戏、装 Mod、管理版本，这些主流启动器都能做。PCL2 的优势在于它把"重复配置"这件事压到了最低：Java 路径自动识别、Mod 加载器一键安装、版本隔离默认开启。

如果你不想在启动器本身上花时间，选一个能让你专心玩游戏而不是折腾工具的工具，就够了。
