**局域网（LAN，Local Area Network）**，指的是在**有限地理范围内**连接多台计算机、手机、服务器、打印机等设备组成的计算机网络。家庭、学校、公司办公室、实验室里的网络，都属于局域网。

简单理解：

> **局域网 = 一群距离较近的设备，通过网络设备互相连接，可以共享资源和通信。**

例如典型的家庭网络：

```
                 Internet
                    |
               光猫/路由器
                    |
        ┌───────────┼───────────┐
        |           |           |
      电脑        手机        NAS服务器
     (LAN)       (WiFi)       (LAN)
```

这些设备之间形成的网络，就是一个**家庭局域网**。

---

## 局域网的特点

### 范围小

通常覆盖：

- 一个房间
- 一套房子
- 一栋办公楼
- 一个校园区域

相比之下：

| 类型 | 英文 | 范围 |
|-----|------|------|
| 个人区域网 | PAN | 几米（蓝牙） |
| 局域网 | LAN | 家庭、办公室 |
| 城域网 | MAN | 城市 |
| 广域网 | WAN | 国家、全球 |

互联网本质上是由大量局域网连接形成的更大网络。

---

### 速度快，延迟低

因为设备距离近，数据不需要经过运营商的大量网络节点。

例如电脑访问家庭 NAS 可能只有 <1ms 延迟、1Gbps 甚至 10Gbps 速度，而访问国外服务器则可能经过运营商的多个节点，延迟高达几十到几百毫秒。

---

### 可以共享资源

局域网常见用途：

- **文件共享**：电脑上的电影、文档共享给电视、手机等设备
- **打印机共享**：公司里所有人使用同一台网络打印机
- **游戏联机**：Minecraft 局域网联机，不需要连接公网服务器

---

## 局域网的组成

### 网卡（NIC）

每台设备都有网卡，负责发送和接收网络数据。

### 交换机（Switch）

局域网核心设备，负责让设备之间互相通信。

```
电脑1 ─┐
电脑2 ─┼── 交换机
电脑3 ─┘
```

### 路由器（Router）

连接不同网络。家用 WiFi 路由器通常同时包含路由器、交换机和无线 AP 的功能。

### 无线接入点（AP）

提供 WiFi 连接。无线局域网通常称为 WLAN，主要基于 IEEE 802.11 标准，也就是常说的 WiFi。

---

## 局域网与互联网的区别

| | 局域网 LAN | 互联网 Internet |
|---|---|---|
| 范围 | 小 | 全球 |
| 管理者 | 个人/公司/学校 | 多组织共同组成 |
| IP 地址 | 私有 IP | 公网 IP |
| 速度 | 快 | 受线路影响 |
| 例子 | 家庭 WiFi | 浏览网页 |

局域网设备通常使用 `192.168.x.x` 这样的私有 IP，而路由器的公网 IP 才是互联网上的身份标识。

---

## 局域网与 [[UDP|UDP]]、[[TCP|TCP]]

局域网提供的是物理链路层和网络层的基础连接，而 UDP/TCP 是在此基础上运行的传输层协议。在局域网中：

- **UDP** 常用于设备发现（如广播发现 NAS）、流媒体传输等
- **TCP** 常用于文件共享、网页访问等需要可靠传输的场景

局域网的高速度和低延迟使得 UDP 的丢包率极低，这也是局域网内流媒体和游戏体验更好的原因之一。

## Tailscale

[[工具分享#Tailscale|Tailscale]] 实际上是在**模拟一个虚拟局域网（Virtual LAN）**。

普通局域网需要设备物理连接在同一交换机或路由器下，而 Tailscale 通过 Overlay Network（覆盖网络）技术，让分布在不同城市的设备拥有虚拟局域网地址（如 `100.x.x.x`），像在同一个局域网中通信。
