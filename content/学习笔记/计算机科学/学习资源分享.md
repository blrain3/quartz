## 📐 数学

[Linear Algebra Done Right](https://linear.axler.net/) — Axler 著。线性代数经典教材，从向量空间讲起，不依赖行列式，适合有一定基础后重读。

[Class Notes 2025 — CME 302 Numerical Linear Algebra](https://ericdarve.github.io/NLA/content/intro.html) — Eric Darve 著。斯坦福数值线性代数课程笔记，涵盖矩阵分解、迭代方法等。

[Calculus Made Easy](https://calculusmadeeasy.org/) — Thompson 1910 年的微积分入门经典，非常通俗易懂，我记得这本教科书！

[A Programmer's Introduction to Mathematics](https://pimbook.org/) — Jeremy Kun 著。面向程序员的数学书，用编程思维讲数学，代码示例丰富。

[Introduction to Real Analysis](https://alexkontorovich.github.io/2025F311H/) — 罗格斯大学实分析课程教材。

[Lean Game Server](https://adam.math.hhu.de/#/g/AlexKontorovich/RealAnalysisGame) — 罗格斯大学 Math 311H，[Alex Kontorovich](https://math.rutgers.edu/~alexk) 著。用 Lean 证明助手做的交互式实分析游戏，边玩边学。

**群论讲义：** [群论讲义 PDF](https://www.damtp.cam.ac.uk/user/ho10//GNotes.pdf) — 剑桥大学群论讲义 PDF。


## 💻 编程语言

### Rust

[Comments - The Rust Programming Language](https://rust-book.cs.brown.edu/ch03-04-comments.html) — 布朗大学制作的交互式 Rust 教程，在线运行 + 即时反馈。

[Two Years of Rust](https://borretti.me/article/two-years-of-rust) — Fernando Borretti 著。使用 Rust 两年后的经验反思，讨论了优点和痛点。

[Title Page - The Rust Performance Book](https://nnethercote.github.io/perf-book/) — Rust 性能优化小册子，教你写出更快的 Rust 代码。

### C / C++

[Learn CPP](https://www.learncpp.com/) — 免费的 C++ 教程网站，从基础语法到高级特性全覆盖，结构清晰。

[ctut](http://usamimi.info/~suwa/ctut.htm#1_1) — usamimi 的 C 语言简明教程，适合快速入门。

[Abstract Syntax Tree: An Example in C](https://keleshev.com/abstract-syntax-tree-an-example-in-c/) — 用 C 语言实现抽象语法树的详细教程，编译原理入门好材料。

### Erlang / BEAM

[The BEAM Book: Understanding the Erlang Runtime System](https://blog.stenmans.org/theBeamBook/) — 深入 Erlang 虚拟机 BEAM 运行时的全书，理解并发和容错机制的底层原理。

### 编程语言理论

[PLT by steshaw](https://steshaw.org/plt/) — 编程语言理论阅读清单，Steven Shaw 整理的从入门到深入的学习路线。


## 🏗️ 软件工程

[The Missing Semester of Your CS Education](https://missing.csail.mit.edu/) — MIT CSAIL 出品。计算机课程之外的重要工程技能：Shell、Git、Vim、SSH、Debugging、构建系统、自动化。

[Google Engineering Practices](https://google.github.io/eng-practices/) — Google 工程团队代码规范。涵盖 Code Review、测试、文档、代码质量。


## 🧮 算法与数据结构

[About · Data Structures](https://datastructures.maximal.io/) — [Maxim Aleksa](http://maximal.io/) 著。交互式数据结构可视化教程，直观理解各种结构的工作原理。

[Algorithms Books](https://algorithmsbook.com/) — 3 本算法电子书合集，涵盖基础算法到高级主题。

[MIT 6.006 — Introduction to Algorithms](https://ocw.mit.edu/courses/6-006-introduction-to-algorithms/) — MIT 算法入门课程。涵盖算法分析、排序、搜索、哈希、图算法、动态规划。

[MIT 6.046 — Design and Analysis of Algorithms](https://ocw.mit.edu/courses/6-046j-design-and-analysis-of-algorithms/) — 高级算法分析。涵盖 NP 完全、随机算法、高级数据结构。

[Build Your Own Text Editor](https://viewsourcecode.org/snaptoken/kilo/) — snaptoken。从零用 C 写一个文本编辑器，逐行讲解代码，动手实践极佳。

[Build Your Own X](https://github.com/codecrafters-io/build-your-own-x) — 从零实现各种软件系统，包括 Redis、Git、Docker、Shell、HTTP Server、Database 等。

[GitHub - snaptoken/leg: 用于制作逐步骤代码讲解的工具](https://github.com/snaptoken/leg) — 用来制作逐行讲解教程的工具。

[Justin Skycak](https://www.justinmath.com/books/#introduction-to-algorithms-and-machine-learning) — 这人的一系列书，属于加速制高中数学/计算机科学课程项目。


## 🖥️ 操作系统

[Operating Systems: Three Easy Pieces](https://pages.cs.wisc.edu/~remzi/OSTEP/) — 最著名的免费 OS 教材之一，围绕虚拟化、并发、持久化三大主题展开。

> 欢迎来到 **Operating Systems: Three Easy Pieces**（当前版本 **1.10**——详见[书籍动态](https://pages.cs.wisc.edu/~remzi/OSTEP/combined.html)），一本免费在线操作系统教材！全书围绕操作系统的三个核心概念展开：**虚拟化**、**并发**和**持久化**。在理解概念的同时，你也会学到实践知识，包括操作系统如何调度 CPU、管理内存以及持久化存储文件。乐趣无穷！或者[未必](https://pic4.zhimg.com/v2-522ded6304485cdac723f25d03c012dd_1200x500.jpg)？

[Writing an OS in Rust](https://os.phil-opp.com/) — Philipp Oppermann 著。用 Rust 从零写一个操作系统的超详细教程系列，含内核、中断、内存管理等。

[Fundamental of Virtual Memory | Melatoni](https://nghiant3223.github.io/2025/05/29/fundamental_of_virtual_memory.html) — 虚拟内存底层原理详解，页表、TLB、MMU 全覆盖。

[Write your Own Virtual Machine](https://www.jmeiners.com/lc3-vm/) — 用 C 编写一个 LC-3 虚拟机，理解计算机指令执行的核心。

## 🌐 网络 & 分布式系统

### 网络

[Stanford CS144 — Computer Networking](https://cs144.github.io/) — 动手实现 TCP/IP 网络协议。涵盖 Ethernet、IP、TCP、路由器、网络栈。项目包括实现自己的 TCP。

[Computer Networking: A Top-Down Approach](https://gaia.cs.umass.edu/kurose_ross/) — Kurose & Ross 经典教材配套资源，自顶向下理解计算机网络。

### 分布式系统

[Notes on Distributed Systems for Young Bloods – Something Similar](https://www.somethingsimilar.com/2013/01/14/notes-on-distributed-systems-for-young-bloods/#services) — Jeff Hodges 著。分布式系统入门必读文章，提炼了核心概念和实战教训。

[CS 153: Infrastructure at Scale](https://cs153.stanford.edu/) — 斯坦福大学大规模基础设施课程，涵盖分布式存储、计算、调度等。

[Distributed Systems Reading List](https://dancres.github.io/Pages/) — Dan Creswell 著。分布式系统精选书单和论文列表，系统学习路线图。


## 💾 数据库

[CMU 15-445 — Database Systems](https://15445.courses.cs.cmu.edu/) — 世界顶级数据库课程之一。涵盖存储引擎、Buffer Pool、索引、查询优化、事务。项目：实现数据库组件。

[Designing Data-Intensive Applications](https://dataintensive.net/) — Martin Kleppmann 著。分布式系统和数据库架构经典。学习数据模型、Replication、Partition、一致性、Stream Processing。
