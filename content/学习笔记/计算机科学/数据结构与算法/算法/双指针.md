#双指针

**双指针（Two Pointers）** 使用两个指针协同遍历数据结构，避免嵌套循环。两个指针可以同向移动、相向移动，或一快一慢，适用于数组、链表等线性结构的特定问题。

> 核心思想：**两个指针比一个指针多一个维度，可以避免嵌套循环。**

---

## 一、相向双指针

两个指针分别从数组两端向中间移动，常用于有序数组。

### 1. 两数之和（有序数组）

> 给定有序数组和目标值，找到两个数使其和等于目标值。

```java
int[] twoSum(int[] nums, int target) {
    int left = 0, right = nums.length - 1;
    while (left < right) {
        int sum = nums[left] + nums[right];
        if (sum == target)
            return new int[]{left, right};
        else if (sum < target)
            left++;      // 和太小，左指针右移（增大和）
        else
            right--;     // 和太大，右指针左移（减小和）
    }
    return new int[]{-1, -1};
}
```

时间复杂度：$O(n)$，空间复杂度：$O(1)$

### 2. 三数之和

> 找到数组中所有和为 0 的三元组。

```java
List<List<Integer>> threeSum(int[] nums) {
    Arrays.sort(nums);
    List<List<Integer>> result = new ArrayList<>();
    for (int i = 0; i < nums.length - 2; i++) {
        if (i > 0 && nums[i] == nums[i-1]) continue;  // 去重
        int left = i + 1, right = nums.length - 1;
        while (left < right) {
            int sum = nums[i] + nums[left] + nums[right];
            if (sum == 0) {
                result.add(Arrays.asList(nums[i], nums[left], nums[right]));
                while (left < right && nums[left] == nums[left+1]) left++;
                while (left < right && nums[right] == nums[right-1]) right--;
                left++; right--;
            } else if (sum < 0) left++;
            else right--;
        }
    }
    return result;
}
```

## 二、同向双指针（滑动窗口）

两个指针从同一端出发，右指针负责扩张，左指针在满足条件时收缩。

### 3. 无重复字符的最长子串

```java
int lengthOfLongestSubstring(String s) {
    Set<Character> set = new HashSet<>();
    int left = 0, maxLen = 0;
    for (int right = 0; right < s.length(); right++) {
        while (set.contains(s.charAt(right))) {
            set.remove(s.charAt(left));
            left++;                       // 收缩窗口
        }
        set.add(s.charAt(right));
        maxLen = Math.max(maxLen, right - left + 1);
    }
    return maxLen;
}
```

### 4. 长度最小的子数组

> 找出该数组中满足其和 ≥ target 的长度最小的子数组。

```java
int minSubArrayLen(int target, int[] nums) {
    int left = 0, sum = 0, minLen = Integer.MAX_VALUE;
    for (int right = 0; right < nums.length; right++) {
        sum += nums[right];                // 扩张窗口
        while (sum >= target) {
            minLen = Math.min(minLen, right - left + 1);
            sum -= nums[left];             // 收缩窗口
            left++;
        }
    }
    return minLen == Integer.MAX_VALUE ? 0 : minLen;
}
```

## 三、快慢指针

两个指针以不同速度移动，常用于链表问题。

### 5. 判断链表是否有环

```java
boolean hasCycle(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;        // 慢指针一次走一步
        fast = fast.next.next;   // 快指针一次走两步
        if (slow == fast) return true;  // 相遇则有环
    }
    return false;
}
```

### 6. 寻找链表中点

```java
ListNode findMiddle(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
    }
    return slow;  // 慢指针指向中点
}
```

### 7. 寻找链表的倒数第 k 个节点

```java
ListNode findKthFromEnd(ListNode head, int k) {
    ListNode fast = head, slow = head;
    // 快指针先走 k 步
    for (int i = 0; i < k; i++) {
        if (fast == null) return null;
        fast = fast.next;
    }
    // 两个指针同步前进
    while (fast != null) {
        slow = slow.next;
        fast = fast.next;
    }
    return slow;  // 当快指针到末尾时，慢指针就在倒数第 k 个
}
```

## 双指针类型总结

| 类型 | 指针移动方式 | 典型问题 | 复杂度 |
|:----|:-----------|:--------|:------|
| **相向** | `left →, ← right` | 两数之和、三数之和、回文判断 | $O(n)$ |
| **同向（滑动窗口）** | `right →`（扩张），`left →`（收缩） | 无重复子串、最小子数组 | $O(n)$ |
| **快慢** | `fast` 比 `slow` 快 | 环检测、链表中点、倒数第 k 个 | $O(n)$ |

### 什么时候用双指针？

- 数组/链表需要 **两个位置协同** 才能解决问题
- 暴力解需要 $O(n^2)$ 时，双指针常常能优化到 $O(n)$
- 数据**有序** → 首选相向双指针
- 子数组/子串问题 → 首选滑动窗口
- 链表问题 → 首选快慢指针
