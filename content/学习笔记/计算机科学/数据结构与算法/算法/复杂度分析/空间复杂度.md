#空间复杂度

> 空间复杂度用于衡量算法占用内存空间随着数据量变大时的增长趋势。

这个概念与[[时间复杂度]]非常类似，只需将"运行时间"替换为"占用内存空间"。

---

## 算法相关空间

算法运行时占用的内存主要分为三部分：

| 空间类型 | 说明 | 是否计入复杂度 |
|:--------|:----|:------------|
| **输入空间** | 存储输入数据所占的空间 | 否 通常不计（数据本身不是算法的开销） |
| **暂存空间** | 算法运行时额外开辟的空间（变量、栈帧、辅助数组等） | 是 **核心关注** |
| **输出空间** | 存储输出结果所占的空间 | 注意 一般不计（但某些分析会考虑） |

**空间复杂度通常只考虑"额外的暂存空间"**，即除了输入和输出之外，算法额外开辟的内存。

---

## 推算方法

与时间复杂度类似：

1. 统计算法中**额外开辟的内存空间**
2. 分析这些空间随 $n$ 增长的变化趋势
3. 用大 $O$ 记号表示

---

## 常见空间复杂度

### $O(1)$ 常数空间

算法只使用固定数量的额外变量，不随 $n$ 变化。

```java
void sum(int[] arr) {
    int total = 0;            // O(1)
    for (int i = 0; i < arr.length; i++)
        total += arr[i];
    return total;
}
```

典型：冒泡排序、选择排序、插入排序、堆排序等原地排序。

---

### $O(\log n)$ 对数空间

主要用于**递归调用栈**的空间消耗。

```java
void binarySearch(int[] arr, int left, int right, int target) {
    if (left > right) return;
    int mid = left + (right - left) / 2;
    if (arr[mid] == target) return;
    if (arr[mid] > target)
        binarySearch(arr, left, mid - 1, target);
    else
        binarySearch(arr, mid + 1, right, target);
}
```

第一次调用 → 第二次调用 → ... → 共 $\log n$ 层递归，栈空间 $O(\log n)$。

典型：二分查找、快速排序（平均情况）

---

### $O(n)$ 线性空间

需要额外开辟与 $n$ 成正比的空间。

```java
void copyArray(int[] arr) {
    int n = arr.length;
    int[] copy = new int[n];   // 注意 额外 O(n) 空间
    for (int i = 0; i < n; i++)
        copy[i] = arr[i];
}
```

典型场景：
- 归并排序的辅助数组 $O(n)$
- 计数排序的计数数组 $O(k)$
- 哈希表存储 $n$ 个元素 $O(n)$
- 动态规划的 DP 表 $O(n)$

递归深度为 $n$ 的递归（如斐波那契朴素递归）也是 $O(n)$ 栈空间。

---

### $O(n^2)$ 平方空间

需要二维数组级别的额外空间。

```java
void createMatrix(int n) {
    int[][] matrix = new int[n][n];  // 注意 O(n²)
}
```

典型：图的邻接矩阵、0-1 背包的二维 DP 表。

---

## 常见复杂度对比

```
O(1) < O(log n) < O(n) < O(n²) < O(2ⁿ)
```

| 复杂度 | 典型算法 | 原因 |
|:-----|:--------|:----|
| $O(1)$ | 冒泡、选择、插入、堆排 | 原地交换，无额外数组 |
| $O(\log n)$ | 二分查找、快排（平均） | 递归栈深度 |
| $O(n)$ | 归并排序、计数排序 | 需要与原数组等长的辅助数组 |
| $O(n^2)$ | 邻接矩阵、二维 DP | 二维数组 |
| $O(2^n)$ | 子集生成（递归） | 指数级递归栈 |

---

## 时间与空间的权衡

**空间换时间**是算法设计中常见策略：

| 策略 | 空间代价 | 时间收益 |
|:----|:--------|:--------|
| DP 用数组存子问题解 | $O(n)$ 或 $O(n^2)$ | 避免指数级重复计算 |
| 哈希表缓存结果（记忆化） | $O(n)$ | 将 $O(2^n)$ 优化到 $O(n)$ |
| 预计算/打表 | 额外存储 | 查询 $O(1)$ |

> 典型例子：斐波那契数列
> - 朴素递归：$O(1)$ 空间，$O(2^n)$ 时间
> - DP 自底向上：$O(n)$ 空间，$O(n)$ 时间
> - DP 滚动变量：$O(1)$ 空间，$O(n)$ 时间（兼具空间和时间优势）
