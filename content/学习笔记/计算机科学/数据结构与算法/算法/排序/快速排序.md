**快速排序（quick sort）** 是基于分治策略的排序算法，运行高效，应用广泛。

## 算法原理
1. 选取数组最左端元素作为基准数，初始化两个指针 `i` 和 `j` 分别指向数组的两端。
2. 设置一个循环，在每轮中使用 `i`（`j`）分别寻找第一个比基准数大（小）的元素，然后交换这两个元素。
3. 循环执行步骤 `2` ，直到 `i` 和 `j` 相遇时停止，最后将基准数交换至两个子数组的分界线。
[![File:Quicksort-example.gif](https://upload.wikimedia.org/wikipedia/commons/9/9c/Quicksort-example.gif?_=20110419161403)](https://upload.wikimedia.org/wikipedia/commons/9/9c/Quicksort-example.gif)

哨兵划分完成后，原数组被划分成三部分：左子数组、基准数、右子数组，且满足“左子数组任意元素  基准数  右子数组任意元素”。因此，我们接下来只需对这两个子数组进行排序。
>[!快速排序的分治策略]
>哨兵划分的实质是将一个较长数组的排序问题简化为两个较短数组的排序问题。


## 算法流程

1. 首先，对原数组执行一次“哨兵划分”，得到未排序的左子数组和右子数组。
2. 然后，对左子数组和右子数组分别递归执行“哨兵划分”。
3. 持续递归，直至子数组长度为 1 时终止，从而完成整个数组的排序。
![快速排序流程](https://www.hello-algo.com/chapter_sorting/quick_sort.assets/quick_sort_overview.png)

Code
```java
/* 快速排序 */
void quickSort(int[] nums, int left, int right) {
    // 子数组长度为 1 时终止递归
    if (left >= right)
        return;
    // 哨兵划分
    int pivot = partition(nums, left, right);
    // 递归左子数组、右子数组
    quickSort(nums, left, pivot - 1);
    quickSort(nums, pivot + 1, right);
}
```

```cpp
/* 快速排序 */
void quickSort(vector<int> &nums, int left, int right) {
    // 子数组长度为 1 时终止递归
    if (left >= right)
        return;
    // 哨兵划分
    int pivot = partition(nums, left, right);
    // 递归左子数组、右子数组
    quickSort(nums, left, pivot - 1);
    quickSort(nums, pivot + 1, right);
}
```

## 算法特性

- **时间复杂度为$O(n\log n)$、非自适应排序**：在平均情况下，哨兵划分的递归层数为$\log n$，每层中的总循环数为$n$，总体使用$O(n\log n)$时间。在最差情况下，每轮哨兵划分操作都将长度为$n$的数组划分为长度为$0$和$n-1$的两个子数组，此时递归层数达到$n$，每层中的循环数为$n$，总体使用$O(n^2)$时间。
- **空间复杂度为$O(n)$**、原地排序：在输入数组完全倒序的情况下，达到最差递归深度$n$，使用$O(n)$栈帧空间。排序操作实在原数组上进行的，为借助额外数组。
- **非稳定排序**：在哨兵划分的最后一步，基准数可能会被交换至相等元素的右侧。

## 快速排序为什么快

* **出现最差情况的概率很低**：绝大多数情况下，快速排序能在$O(n\log n)$的时间复杂度下运行。
* **缓存使用率高**：在执行哨兵划分操作时，系统可以将整个子数组加载到缓存，因此访问元素的效率较高。
* **复杂度的场数系数小**：快速排序的比较、赋值、交换等操作的总数量更少。


## 基准数优化

快速排序的最坏情况 $O(n^2)$ 出现在每次选的基准数都是极端值（最小值或最大值）时，例如数组已经有序时取最左端元素作为基准。

### 策略一：随机基准
```java
int pivotIndex = left + (int)(Math.random() * (right - left + 1));
swap(nums, left, pivotIndex);  // 将随机选的基准交换到最左端
```
- 优点：从概率上避免最坏情况
- 缺点：随机数生成有少量开销

### 策略二：三数取中（Median-of-Three）
```java
int medianPivot(int[] nums, int left, int right) {
    int mid = left + (right - left) / 2;
    // 将 left、mid、right 三个位置的中位数交换到 left
    if (nums[left] > nums[mid]) swap(nums, left, mid);
    if (nums[left] > nums[right]) swap(nums, left, right);
    if (nums[mid] > nums[right]) swap(nums, mid, right);
    // 现在 nums[left] ≤ nums[mid] ≤ nums[right]
    swap(nums, left, mid);  // 将中位数作为基准放到最左端
    return nums[left];
}
```
- 优点：对已有序数组效果极好，能有效避免最坏情况
- 实际中三数取中比随机基准更常用

## 递归深度优化

快速排序的递归深度在最坏情况下可达 $n$（数组已有序 + 取最左端基准），有栈溢出风险。

### 策略一：尾递归优化
将递归调用改为对**较短子数组**递归，较长子数组用迭代处理：
```java
void quickSortOptimized(int[] nums, int left, int right) {
    while (left < right) {
        int pivot = partition(nums, left, right);
        // 对较短的一边递归，较长的一边迭代
        if (pivot - left < right - pivot) {
            quickSortOptimized(nums, left, pivot - 1);
            left = pivot + 1;  // 处理右半部分
        } else {
            quickSortOptimized(nums, pivot + 1, right);
            right = pivot - 1;  // 处理左半部分
        }
    }
}
```
- 最坏递归深度降为 $O(\log n)$
- 避免了栈溢出风险

### 策略二：小区间切换到插入排序
```java
void quickSortHybrid(int[] nums, int left, int right) {
    // 小区间使用插入排序
    if (right - left < 10) {
        insertionSort(nums, left, right);
        return;
    }
    int pivot = partition(nums, left, right);
    quickSortHybrid(nums, left, pivot - 1);
    quickSortHybrid(nums, pivot + 1, right);
}
```
- 当子数组长度小于阈值（通常为 10-20）时，切换到插入排序
- 减少递归深度 + 利用插入排序在小规模数据上的优势
