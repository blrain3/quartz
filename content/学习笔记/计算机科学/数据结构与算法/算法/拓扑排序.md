## 一、基本概念

### 1. 拓扑排序的定义

拓扑排序是对**有向无环图（DAG，Directed Acyclic Graph）**中顶点的一种线性排序。

对于图中的任意一条有向边：
```text
u → v
```
在拓扑序列中，顶点 u 必须排在顶点 v 的前面。

---

### 2. 适用条件

拓扑排序只能应用于：

**有向无环图（DAG）**

若图中存在环路（Cycle），则无法进行拓扑排序。

---

## 二、拓扑排序的应用场景

拓扑排序主要用于解决具有先后依赖关系的问题。

典型应用：

1. 课程安排
    
    - 先修课程必须先完成
        
2. 项目管理
    
    - 某些任务必须在其他任务完成后才能开始
        
3. 软件编译
    
    - 模块之间存在依赖关系
        
4. 工作流程调度
    
    - 按照依赖关系安排执行顺序
        

---

## 三、相关概念

### 1. 顶点（Vertex）

图中的每个节点。

例如：

```text
A、B、C、D
```

---

### 2. 有向边（Directed Edge）

表示两个顶点之间的先后关系。

```text
A → B
```

表示：

A 必须先于 B。

---

### 3. 入度（In-degree）

一个顶点的入度是指：

**指向该顶点的边数。**

例如：

```text
A → C ← B
```

|顶点|入度|
|---|---|
|A|0|
|B|0|
|C|2|

---

### 4. 出度（Out-degree）

一个顶点的出度是指：

**从该顶点发出的边数。**

例如：

```text
A → B
↓
C
```

A 的出度为 2。

---

## 四、拓扑排序的基本思想

核心思想：

不断选择入度为 0 的顶点。

原因：

入度为 0 表示该顶点没有前驱结点，可以优先执行。

处理步骤：

1. 找出所有入度为 0 的顶点；
    
2. 输出其中一个顶点；
    
3. 删除该顶点及其所有出边；
    
4. 更新相关顶点的入度；
    
5. 重复上述过程，直到图为空。
    

---

## 五、拓扑排序示例

给定有向图：

```text
A → B → D
↓
C → D
```

### 第一步：统计入度

|顶点|入度|
|---|---|
|A|0|
|B|1|
|C|1|
|D|2|

---

### 第二步：输出 A

删除 A 的出边：

```text
A → B
A → C
```

更新入度：

|顶点|入度|
|---|---|
|B|0|
|C|0|
|D|2|

---

### 第三步：输出 B

删除：

```text
B → D
```

更新：

```text
D: 2 → 1
```

---

### 第四步：输出 C

删除：

```text
C → D
```

更新：

```text
D: 1 → 0
```

---

### 第五步：输出 D

最终拓扑序列：

```text
A B C D
```

或：

```text
A C B D
```

均正确。

---

## 六、拓扑排序算法（Kahn算法）

### 伪代码

```text
计算所有顶点的入度

将所有入度为0的顶点加入队列

WHILE 队列非空 DO

    取出队首顶点v

    输出v

    FOR v的每个邻接顶点u DO

        入度[u]--

        IF 入度[u] = 0 THEN
            u入队
        ENDIF

    ENDFOR

ENDWHILE
```

## 七、判断图中是否存在环

拓扑排序的重要应用：

### 判断是否有环

设：

- 图中共有 n 个顶点；
    
- 拓扑排序后输出了 count 个顶点。
    

若：

```text
count = n
```

则：

图中无环。

若：

```text
count < n
```

则：

图中存在环。

原因：

环中的顶点入度始终无法降为 0。

## 八、时间复杂度分析

采用邻接表实现：

- 每个顶点访问一次
    
- 每条边访问一次
    

时间复杂度：

```text
O(V + E)
```

其中：

- V：顶点数
    
- E：边数
    
空间复杂度：

```text
O(V)
```
