#二分查找

**二分查找（Binary Search）** 在有序数组中查找目标值，每次取中间值与目标比较，根据比较结果排除一半的搜索范围，将时间复杂度控制在 $O(\log n)$。

> 核心思想：**每次取中间值与目标比较，排除一半不可能的区域。**

---

### 标准二分查找

#### Java

```java
int binarySearch(int[] nums, int target) {
    int left = 0, right = nums.length - 1;
    while (left <= right) {
        int mid = left + (right - left) / 2;  // 防止溢出
        if (nums[mid] == target)
            return mid;
        else if (nums[mid] < target)
            left = mid + 1;     // 目标在右半部分
        else
            right = mid - 1;    // 目标在左半部分
    }
    return -1;  // 未找到
}
```

#### C++

```cpp
int binarySearch(vector<int>& nums, int target) {
    int left = 0, right = nums.size() - 1;
    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (nums[mid] == target) return mid;
        else if (nums[mid] < target) left = mid + 1;
        else right = mid - 1;
    }
    return -1;
}
```

#### Python

```python
def binary_search(nums: list[int], target: int) -> int:
    left, right = 0, len(nums) - 1
    while left <= right:
        mid = left + (right - left) // 2
        if nums[mid] == target:
            return mid
        elif nums[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return -1
```

---

### 二分查找的三种模板

| 模板 | 区间 | while 条件 | mid 取值 | 适用场景 |
|:----|:----|:---------|:--------|:--------|
| **标准** | `[left, right]` | `left <= right` | `mid` | 查找确切值 |
| **左闭右开** | `[left, right)` | `left < right` | `mid` | 查找左边界 |
| **左开右闭** | `(left, right]` | `left < right` | `mid + 1` | 查找右边界 |

### 常见变体

#### 1. 查找第一个 ≥ target 的位置（左边界）

```java
int lowerBound(int[] nums, int target) {
    int left = 0, right = nums.length;  // 区间 [left, right)
    while (left < right) {
        int mid = left + (right - left) / 2;
        if (nums[mid] >= target)
            right = mid;      // 左区间继续找
        else
            left = mid + 1;   // 右区间
    }
    return left;
}
```

#### 2. 查找第一个 > target 的位置（右边界+1）

```java
int upperBound(int[] nums, int target) {
    int left = 0, right = nums.length;
    while (left < right) {
        int mid = left + (right - left) / 2;
        if (nums[mid] > target)
            right = mid;
        else
            left = mid + 1;
    }
    return left;
}
```

#### 3. 在旋转有序数组中搜索

```java
int searchRotated(int[] nums, int target) {
    int left = 0, right = nums.length - 1;
    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (nums[mid] == target) return mid;

        if (nums[left] <= nums[mid]) {          // 左半部分有序
            if (target >= nums[left] && target < nums[mid])
                right = mid - 1;
            else
                left = mid + 1;
        } else {                                 // 右半部分有序
            if (target > nums[mid] && target <= nums[right])
                left = mid + 1;
            else
                right = mid - 1;
        }
    }
    return -1;
}
```

### 算法特性

| 特性 | 说明 |
|:----|:----|
| 时间复杂度 | $O(\log n)$ |
| 空间复杂度 | $O(1)$（迭代）或 $O(\log n)$（递归） |
| 前置条件 | 数组必须**有序** |

### 二分查找的常见错误

| 错误 | 后果 | 正确做法 |
|:----|:----|:--------|
| `mid = (left + right) / 2` | 整数溢出 | `left + (right - left) / 2` |
| while 条件写错 | 死循环或漏解 | 明确区间的开闭方式 |
| 边界更新不对 | 遗漏元素或死循环 | 根据区间定义一致地更新 left/right |

### 应用场景

- **有序数组的查找**：基础场景
- **求平方根**：在 [0, x] 范围内二分查找
- **峰值查找**：在无序数组中找局部峰值
- **旋转数组搜索**：在经旋转后的有序数组中查找
- **搜索区间**：查找某个值出现的第一个和最后一个位置
