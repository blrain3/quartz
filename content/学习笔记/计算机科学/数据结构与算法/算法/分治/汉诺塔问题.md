#汉诺塔问题

>[!Question]
>给定三根柱子，记为 `A`、`B` 和 `C`。起始状态下，柱子 `A` 上套着 $n$ 个圆盘，它们从上到下按照从小到大的顺序排列。我们的任务是要把这 $n$ 个圆盘移到柱子 `C` 上，并保持它们的原有顺序不变，在移动圆盘的过程中，需要遵守以下规则。
>1. 圆盘只能从一根柱子顶部拿出，从另一根柱子顶部放入。
>2. 每次只能移动一个圆盘。
>3. 小圆盘必须时刻位于大圆盘之上。

---

### 递归分析

汉诺塔问题的递归思路：

1. **将 A 上面的 $n-1$ 个盘子** → 借助 C 移到 B
2. **将 A 最下面的 1 个最大的盘子** → 直接移到 C
3. **将 B 上的 $n-1$ 个盘子** → 借助 A 移到 C

```
汉诺塔(n, A, B, C)：
    1. 汉诺塔(n-1, A, C, B)    # 将 n-1 个从 A → B（借助 C）
    2. 移动 A → C                # 将最大的从 A → C
    3. 汉诺塔(n-1, B, A, C)    # 将 n-1 个从 B → C（借助 A）
```

### 代码实现

#### Java

```java
void hanoi(int n, char A, char B, char C) {
    if (n == 1) {
        System.out.println(A + " → " + C);  // 只有一个盘子，直接移动
        return;
    }
    hanoi(n - 1, A, C, B);  // 将 n-1 个盘子从 A 移到 B（借助 C）
    System.out.println(A + " → " + C);      // 将最底下的盘子从 A 移到 C
    hanoi(n - 1, B, A, C);  // 将 n-1 个盘子从 B 移到 C（借助 A）
}
```

#### C++

```cpp
void hanoi(int n, char A, char B, char C) {
    if (n == 1) {
        cout << A << " → " << C << endl;
        return;
    }
    hanoi(n - 1, A, C, B);
    cout << A << " → " << C << endl;
    hanoi(n - 1, B, A, C);
}
```

#### Python

```python
def hanoi(n: int, A: str, B: str, C: str):
    if n == 1:
        print(f"{A} → {C}")
        return
    hanoi(n - 1, A, C, B)     # 将 n-1 个从 A 移到 B
    print(f"{A} → {C}")        # 将最底下的从 A 移到 C
    hanoi(n - 1, B, A, C)     # 将 n-1 个从 B 移到 C
```

### 移动次数

汉诺塔的移动次数递推公式：

$$T(1) = 1$$
$$T(n) = 2 \times T(n-1) + 1$$

解得：

$$T(n) = 2^n - 1$$

| n | 移动次数 | 
|:-:|:--------:|
| 1 | 1 |
| 3 | 7 |
| 5 | 31 |
| 10 | 1023 |
| 64 | $2^{64} - 1 \approx 1.84 \times 10^{19}$ |

### 算法特性

| 特性 | 说明 |
|:----|:----|
| 时间复杂度 | $O(2^n)$ |
| 空间复杂度 | $O(n)$（递归栈深度） |
| 策略 | 分治（将 n 的问题拆为两个 n-1 的问题） |

> 传说中僧侣们要移动 64 个金盘，即使每秒钟移动一次，总共需要约 $1.84 \times 10^{19}$ 秒，合约 5850 亿年，远远超过了目前对宇宙年龄的估计。

### 思考

汉诺塔是学习**递归**和**分治**的最佳入门问题之一。它的代码极其简洁，但要真正想通为什么这么写，需要理解"把 $n-1$ 个盘子当作整体看"的分治思维——这正是递归的精髓。
