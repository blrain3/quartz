#串

**串（String）** 是由零个或多个字符组成的有限序列。字符串处理是程序设计中最为基础且常见的操作之一。

---

## KMP 算法

KMP（Knuth-Morris-Pratt）算法是一种高效的字符串匹配算法。它通过利用**部分匹配信息**，避免主串指针回溯，将匹配时间复杂度从 $O(n \times m)$ 优化到 $O(n + m)$。

### 核心思想

- 当匹配失败时，**主串指针不回退**，只移动模式串
- 利用 **next 数组** 记录模式串自身的前缀-后缀匹配信息，指导模式串跳跃到合适位置

### 前缀表（next 数组）

`next[i]` 表示模式串 `P[0..i]` 中**最长相等前后缀的长度**（或常用的 next 数组表示"匹配失败后应跳转的位置"）。

| 模式串 | A | B | A | C | A | B | A |
|:-----:|:-:|:-:|:-:|:-:|:-:|:-:|:-:|
| 索引 i | 0 | 1 | 2 | 3 | 4 | 5 | 6 |
| next[i] | 0 | 0 | 1 | 0 | 1 | 2 | 3 |

> 如 `next[5] = 2` 表示 `P[0..5] = "ABACAB"` 中，最长相等前后缀长度为 2（前缀 "AB" = 后缀 "AB"）。

### Java 实现

```java
/* 构建 next 数组 */
int[] buildNext(String pattern) {
    int m = pattern.length();
    int[] next = new int[m];
    int j = 0;
    for (int i = 1; i < m; i++) {
        while (j > 0 && pattern.charAt(i) != pattern.charAt(j))
            j = next[j - 1];
        if (pattern.charAt(i) == pattern.charAt(j))
            j++;
        next[i] = j;
    }
    return next;
}

/* KMP 匹配 */
int kmp(String text, String pattern) {
    int n = text.length(), m = pattern.length();
    if (m == 0) return 0;
    int[] next = buildNext(pattern);
    int j = 0;
    for (int i = 0; i < n; i++) {
        while (j > 0 && text.charAt(i) != pattern.charAt(j))
            j = next[j - 1];
        if (text.charAt(i) == pattern.charAt(j))
            j++;
        if (j == m)
            return i - m + 1;  // 匹配成功
    }
    return -1;  // 匹配失败
}
```

### C++ 实现

```cpp
vector<int> buildNext(const string& pattern) {
    int m = pattern.size();
    vector<int> next(m, 0);
    for (int i = 1, j = 0; i < m; i++) {

int kmp(const string& text, const string& pattern) {
    int n = text.size(), m = pattern.size();
    if (m == 0) return 0;
    auto next = buildNext(pattern);
    for (int i = 0, j = 0; i < n; i++) {

            j = next[j - 1];
        if (text[i] == pattern[j]) j++;
        if (j == m) return i - m + 1;
    }
    return -1;
}
```

### Python 实现

```python
def build_next(pattern):
    m = len(pattern)
    next_arr = [0] * m
    j = 0
    for i in range(1, m):
        while j > 0 and pattern[i] != pattern[j]:
            j = next_arr[j - 1]
        if pattern[i] == pattern[j]:
            j += 1
        next_arr[i] = j
    return next_arr

def kmp(text, pattern):
    if not pattern:
        return 0
    n, m = len(text), len(pattern)
    next_arr = build_next(pattern)
    j = 0
    for i in range(n):
        while j > 0 and text[i] != pattern[j]:
            j = next_arr[j - 1]
        if text[i] == pattern[j]:
            j += 1
        if j == m:
            return i - m + 1
    return -1
```

### KMP 算法特性

| 特性 | 说明 |
|:----|:----|
| 时间复杂度 | $O(n + m)$（$n$ 为主串长，$m$ 为模式串长） |
| 空间复杂度 | $O(m)$（next 数组） |
| 核心优势 | 主串指针不回退，适合流式处理 |

### 暴力匹配 vs KMP

| 对比 | 暴力匹配 | KMP |
|:----|:--------|:----|
| 时间复杂度 | $O(n \times m)$ | $O(n + m)$ |
| 主串指针 | 匹配失败时回溯 | 永不回溯 |
| 空间复杂度 | $O(1)$ | $O(m)$ |
| 适用场景 | 短字符串、简单实现 | 长文本、高性能要求 |

## 广义表

广义表（Generalized List）是线性表的推广，表中的元素可以是单元素，也可以是一个子表。

- 广义表的**长度** = 最外层元素的个数
- 广义表的**深度** = 展开后括号的最大嵌套层数
