# 数据结构与算法

> 算法与数据结构是计算机科学的基石。本仓库整理了从基础到进阶的常见数据结构和算法。

---

## 数据结构

| 类型 | 数据结构 | 核心特点 |
|:----|:--------|:--------|
| **线性** | [[数组]] | 连续内存，$O(1)$ 随机访问 |
| | [[链表]] | 动态大小，$O(1)$ 插入/删除（已知位置） |
| | [[栈]] | 后进先出（LIFO），$O(1)$ 操作 |
| | [[队列]] | 先进先出（FIFO），$O(1)$ 操作 |
| | [[哈希表（散列表）|哈希表]] | $O(1)$ 查找/插入，解决冲突：链地址/开放寻址 |
| | [[串]] | 字符串匹配，KMP 算法 |
| **树形** | [[树]] | 二叉树、BST、AVL、红黑树等 |
| | [[堆排序\|堆]] | 完全二叉树，优先级队列的底层 |
| **图形** | [[图]] | 邻接矩阵/邻接表，图的遍历与搜索 |
| **基础** | [[数据基本类型]] | int、float、char 等基本类型 |
| | [[数据结构分类]] | 逻辑结构（线性/非线性）与物理结构（连续/分散） |

### 数据结构复杂度速查

| 数据结构 | 访问 | 查找 | 插入 | 删除 |
|:--------|:---:|:---:|:---:|:---:|
| 数组 | $O(1)$ | $O(n)$ | $O(n)$ | $O(n)$ |
| 链表 | $O(n)$ | $O(n)$ | $O(1)$ | $O(1)$ |
| 栈 | $O(n)$ | $O(n)$ | $O(1)$ | $O(1)$ |
| 队列 | $O(n)$ | $O(n)$ | $O(1)$ | $O(1)$ |
| 哈希表 | — | $O(1)$ 平均 | $O(1)$ 平均 | $O(1)$ 平均 |
| 二叉搜索树 | $O(\log n)$ 平均 | $O(\log n)$ 平均 | $O(\log n)$ 平均 | $O(\log n)$ 平均 |
