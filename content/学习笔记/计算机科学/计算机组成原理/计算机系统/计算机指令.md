程序 = 一串 CPU 指令
CPU = 一台执行指令的机器

---

二、为什么标题叫“纸带编程”？

· 早期计算机用 纸带 输入程序
· 纸带上：有孔 = 1，无孔 = 0
· 纸带直接表示 二进制
· 二进制既可表示 数据，也可表示 指令
· 这是 冯·诺依曼结构 的核心思想：程序也是数据

---

三、从高级语言到机器码

以 a = a + 1 为例：

步骤 产物 示例
编译 汇编代码 ADD R1, 1
汇编 机器码（二进制） 0001 0001 0000 0001

CPU 真正执行的是 二进制机器码，不是高级语言。

---

四、什么是指令？

· CPU 规定某些二进制代表某种操作

二进制 含义
0001 加法
0010 减法
0011 跳转

· CPU 工作流程：读二进制 → 解析含义 → 执行操作

---

五、指令集架构（ISA）

ISA = CPU 能听懂的语言

CPU / 平台 指令集
Intel/AMD x86
Apple M 系列 ARM
手机芯片 ARM
部分服务器 RISC-V

不同指令集不通用 → 同一程序需针对不同 CPU 重新编译

---

六、指令格式

一条指令通常分为：

部分 作用 示例
Opcode 操作码（做什么） ADD
Operand 操作数（对谁操作） R1, R2

示例：ADD R1, R2  →  R1 = R1 + R2

---

七、CPU 执行程序的本质：Fetch–Decode–Execute 循环

1. Fetch（取指）：从内存取下一条指令
2. Decode（译码）：解析指令含义
3. Execute（执行）：真正执行（加法、跳转、读内存等）

CPU 一生都在无限循环这个过程。

---

八、跳转指令的重要性

· 没有跳转，CPU 只能顺序执行 → 无法实现 if、while、for、函数调用

高级语言结构 底层本质
if 条件跳转
while 循环跳转
函数调用 跳转 + 返回

跳转指令是程序逻辑的灵魂

---

九、为什么“程序也是数据”如此重要？

· 程序可以像数据一样放在内存中
· 计算机可 动态加载、修改、运行不同程序
· 否则每次换程序都要重新接线（早期计算机就是这样）

---

十、隐藏主线：从高级语言到机器世界的下潜

```
你写的代码
    ↓ 编译
汇编指令
    ↓ 汇编
机器码（二进制）
    ↓ CPU 取指、译码、执行
电路/晶体管动作
```

程序在 CPU 眼里不是 for 循环，而是 LOAD、CMP、JMP、ADD、STORE 等低级动作。
