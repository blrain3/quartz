计算机包含五大部分，及运算器、控制器、存储器、输入设备和输出设备。[[Cache]] 和 [[数据通路]] 是计算机系统运行中的两个关键子结构，将在相关笔记中详细展开。

## 运算器

>计算机中负责计算（包括算数计算和逻辑计算等）的部件。

运算器包括 *[算数和逻辑运算部件](https://en.wikipedia.org/wiki/Arithmetic_logic_unit)*（Arithmetic Logic Units，ALU）、*[移位部件](https://en.wikipedia.org/wiki/Shift_register)*、*[浮点运算部件](https://en.wikipedia.org/wiki/Floating-point_arithmetic)*（Floating Point Units，FPU）、*[向量运算部件](https://www.google.com/search?q=%E5%90%91%E9%87%8F%E8%BF%90%E7%AE%97%E9%83%A8%E4%BB%B6&ie=UTF-8)*（Vector Functional Unit, VFU）、*[寄存器](https://en.wikipedia.org/wiki/Processor_register)* 等。

## 控制器

>计算机中发出控制命令以控制计算机各部件自动、协调地工作的装置。

控制器控制指令流和每条指令的执行，内含[程序计数器](https://en.wikipedia.org/wiki/Program_counter)和[指令寄存器](https://en.wikipedia.org/wiki/Instruction_register)等。程序计数器存放当前执行指令的地址，指令寄存器存放当前正在执行的指令。

|组件|功能|
|:--|:--|
|程序计数器 (PC)|存放当前执行指令的地址|
|指令寄存器 (IR)|存放当前正在执行的指令|
|译码器|产生控制信号|

## 存储器

>存储程序和数据，又称主存储器或内存，一般用动态随机访问存储器（Dynamic Random Access Memory，DRAM）实现。CPU可以直接访问它，IO设备也频繁地与它交换数据。

存储器的存取速度往往满足不了CPU的快速要求，容量也满足不了应用的需要，为此将存储系统分为**高速缓存**[^1]（[Cache](https://en.wikipedia.org/wiki/Cache_(computing)))、**主存储器**[^2]([Main Memory](https://en.wikipedia.org/wiki/Computer_memory))、和**辅助存储器**[^3]([Secondary Storage](https://en.wikipedia.org/wiki/Computer_data_storage))三个层次。

目前人们发明的用于计算机系统的存储介质主要包括以下几类：
1. 磁性存储介质。如硬盘、磁带等。具有非易失性（断电后数据可长期保存），缺点是访问速度慢。
2. 闪存（Flash Memory）。同样具有非易失性，与磁盘相比，访问速度快、成本高、容量小。
3. 动态随机访问存储器（DRAM）。属于易失性存储器（断电后数据丢失）。特点是存储密度高需要周期性刷新，访问速度快。
4. 静态随机访问存储器（SRAM）。属于易失性存储器（断电后数据丢失）。存储密度不如DRAM高，不用周期性刷新，但访问速度比DRAM快，可以达到纳秒级。

[^1]:**高速缓存 (Cache)** 是位于**CPU 与主存 (RAM) 之间**的**超高速小容量存储器**，用**SRAM (静态随机存取存储器)** 制造，速度接近 CPU，容量远小于主存，成本极高。它是计算机存储层次结构的关键一环，核心作用是**缓冲 CPU 与主存的速度鸿沟**，减少 CPU 等待数据的时间，提升整体性能。

[^2]:**主存储器（Main Memory，简称主存 / 内存）** 是计算机系统中**CPU 可直接访问**的核心存储部件，位于**高速缓存 (Cache) 与辅助存储器 (外存)** 之间，用于**临时存放当前正在运行的程序和数据**，是 CPU 与外存之间的 “数据桥梁”。可以把它想象成**卧室里的大书架**，比书桌 (Cache) 大很多，能放最近常用的所有书籍，但比楼下仓库 (外存) 小，且断电后书架上的书会消失。

[^3]:**辅助存储器（Secondary Storage，简称辅存或外存）** 是**计算机中用于长期、永久性存储数据和程序的非易失性设备**。与内存相比，它容量极大、价格较低，但读写速度较慢。常见类型包括硬盘驱动器（HDD）、固态硬盘（SSD）、U盘、光盘及云存储等。

### 主存

| 主存类别         | 作用                         | 特性                  | 类比                 |
| ------------ | -------------------------- | ------------------- | ------------------ |
| RAM（随机存取存储器） | 运行程序、临时存储数据                | **断电即清空**，速度极快      | “工作台”，东西随手可取但关机就清空 |
| ROM（只读存储器）   | 永久存储**固件**，如开机启动的BIOS、UEFI | **断电不丢失**，但内容固定、很难改 | 书架上“之前的日记本”        |
