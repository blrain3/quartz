>帮你自动安装、管理、更新软件及其依赖的工具。
## Windows
### 一、WinGet（微软官方）

> Windows Package Manager，2020年推出，Windows 11内置，Win10 2004+可用

**特点**
- 微软官方出品，原生集成
- 支持 EXE/MSI/MSIX/ZIP 等格式
- 部分操作需管理员权限
- 仓库约 5000+ 包

**常用命令**
```
winget search <包名>           # 搜索
winget install <包ID>          # 安装
winget upgrade <包ID>          # 更新指定包
winget upgrade --all           # 更新所有
winget uninstall <包ID>       # 卸载
winget list                    # 查看已安装
winget export -o myapps.json   # 导出装机清单
winget import myapps.json      # 一键装机
```

### 二、Chocolatey

> 2011年发布，生态最成熟，社区驱动

**特点**
- 仓库最大（9500+ 包）
- 需要管理员权限
- 默认安装到 `C:\ProgramData\chocolatey`
- 适合企业批量部署
- 支持 PowerShell 自动化

**安装**
```powershell
Set-ExecutionPolicy Bypass -Scope Process -Force
iex ((New-Object System.Net.WebClient).DownloadString('https://community.chocolatey.org/install.ps1'))
```

**常用命令**
```
choco install <包名> -y        # 安装
choco upgrade <包名> -y        # 更新
choco uninstall <包名> -y      # 卸载
choco list --local-only        # 查看已安装
```

---

### 三、Scoop

> 灵感来自 Homebrew，专注开发工具，用户级安装

**特点**
- 无需管理员权限
- 安装在用户目录 `C:\Users\<用户名>\scoop`
- 专注便携应用和开发工具
- 支持自定义 bucket 仓库

**安装**
```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
irm get.scoop.sh | iex
```

**常用命令**
```
scoop install <包名>            # 安装
scoop update <包名>             # 更新
scoop uninstall <包名>          # 卸载
scoop list                      # 查看已安装
scoop bucket add <仓库名>       # 添加第三方仓库
```

## Linux

### 一、apt（Debian / Ubuntu）

**适用发行版**：Debian、Ubuntu、Linux Mint 等

**常用命令**
```
sudo apt update                 # 更新软件包列表
sudo apt install <包名>         # 安装
sudo apt upgrade                # 升级所有
sudo apt remove <包名>         # 卸载（保留配置）
sudo apt purge <包名>          # 彻底卸载
apt search <关键词>            # 搜索
dpkg -S <文件路径>             # 查询文件属于哪个包
```

---

### 二、yum / dnf（RedHat 系）

**适用发行版**：RHEL、CentOS（7及之前用 yum，8+用 dnf）、Fedora

**常用命令**
```
sudo yum install <包名>        # 安装
sudo yum update                # 升级所有
sudo yum remove <包名>         # 卸载
yum search <关键词>            # 搜索
yum whatprovides <文件>        # 查询文件属于哪个包
```
> dnf 是 yum 的新一代替代品，命令用法基本一致，速度更快

---

### 三、pacman（Arch Linux）

**适用发行版**：Arch Linux、Manjaro、EndeavourOS

**常用命令**
```
sudo pacman -Syu               # 同步+升级（一步到位）
sudo pacman -S <包名>          # 安装
sudo pacman -R <包名>          # 卸载（保留依赖）
sudo pacman -Rns <包名>         # 彻底卸载
pacman -Ss <关键词>            # 搜索
pacman -Qo <文件>              # 查询文件属于哪个包
```

---

### 四、zypper（SUSE 系）

**适用发行版**：openSUSE、SUSE Linux Enterprise

**常用命令**
```
sudo zypper install <包名>     # 安装
sudo zypper update             # 升级所有
sudo zypper remove <包名>      # 卸载
zypper search <关键词>         # 搜索
zypper what-provides <文件>    # 查询文件属于哪个包
```

---

### 四者对比

| 维度 | apt | yum/dnf | pacman | zypper |
|------|-----|---------|--------|--------|
| 适用发行版 | Debian系 | RedHat系 | Arch系 | SUSE系 |
| 包格式 | .deb | .rpm | .pkg.tar.zst | .rpm |
| 速度 | 中等 | 中等 | 最快 | 中等 |
| 学习曲线 | 低 | 中 | 高 | 中 |
| 仓库规模 | 非常大 | 大 | 大 | 较小 |

## 跨平台

### Homebrew（macOS / Linux）

虽然主要是 macOS 的包管理器，但也支持 Linux：
```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
brew install <包名>
brew update && brew upgrade
```
