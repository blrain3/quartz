**归并排序（merge sort）** 采用分治策略：将数组递归地拆分为两个子数组，分别排序后再合并。与同属分治策略的 [[快速排序]] 不同，归并排序需要额外 $O(n)$ 空间，但能保证 $O(n \log n)$ 的最差时间复杂度且是稳定排序。

![](https://upload.wikimedia.org/wikipedia/commons/c/cc/Merge-sort-example-300px.gif)

1. **划分阶段**：通过递归不断地将数组从中点处分开，将长数组的排序问题转换为短数组的排序问题。
2. **合并阶段**：当子数组长度为 1 时终止划分，开始合并，持续地将左右两个较短的有序数组合并为一个较长的有序数组，直至结束。

![](https://r2.salix.eu.org/obsidian/20260423233024195.webp)

## 算法流程

### 划分阶段
1. 计算数组的中点 `mid = left + (right - left) / 2`
2. 递归地对左半部分 `[left, mid]` 和右半部分 `[mid + 1, right]` 执行排序
3. 当子数组长度为 1 时终止递归

### 合并阶段
核心操作是将两个有序子数组合并为一个有序数组：
1. 创建一个临时数组 `tmp`，长度为两个子数组长度之和
2. 用双指针分别遍历左右两个子数组，将较小者依次放入 `tmp`
3. 将剩余元素复制到 `tmp`
4. 将 `tmp` 的内容复制回原数组的对应位置

## 代码实现

### Java
```java
/* 合并左子数组和右子数组 */
void merge(int[] nums, int left, int mid, int right) {
    // 左子数组区间 [left, mid]，右子数组区间 [mid+1, right]
    int[] tmp = new int[right - left + 1];
    int i = left, j = mid + 1, k = 0;
    // 双指针合并
    while (i <= mid && j <= right) {
        if (nums[i] <= nums[j])
            tmp[k++] = nums[i++];
        else
            tmp[k++] = nums[j++];
    }
    // 将剩余元素放入 tmp
    while (i <= mid)  tmp[k++] = nums[i++];
    while (j <= right) tmp[k++] = nums[j++];
    // 将 tmp 复制回原数组
    for (k = 0; k < tmp.length; k++)
        nums[left + k] = tmp[k];
}

/* 归并排序 */
void mergeSort(int[] nums, int left, int right) {
    if (left >= right) return;
    int mid = left + (right - left) / 2;
    mergeSort(nums, left, mid);
    mergeSort(nums, mid + 1, right);
    merge(nums, left, mid, right);
}
```

### C++
```cpp
void merge(vector<int>& nums, int left, int mid, int right) {
    vector<int> tmp(right - left + 1);
    int i = left, j = mid + 1, k = 0;
    while (i <= mid && j <= right)
        tmp[k++] = nums[i] <= nums[j] ? nums[i++] : nums[j++];
    while (i <= mid)  tmp[k++] = nums[i++];
    while (j <= right) tmp[k++] = nums[j++];
    for (k = 0; k < tmp.size(); k++)
        nums[left + k] = tmp[k];
}

void mergeSort(vector<int>& nums, int left, int right) {
    if (left >= right) return;
    int mid = left + (right - left) / 2;
    mergeSort(nums, left, mid);
    mergeSort(nums, mid + 1, right);
    merge(nums, left, mid, right);
}
```

def merge(nums: list[int], left: int, mid: int, right: int):
    “””合并左子数组和右子数组”””
    tmp = [0] * (right - left + 1)
    i, j, k = left, mid + 1, 0

## 算法特性

| 特性 | 说明 |
|:---|:---|
| 时间复杂度 | 最好/平均/最坏均为 $O(n \log n)$，始终稳定 |
| 空间复杂度 | $O(n)$，需要与原数组等长的临时数组 |
| 稳定性 | 是 稳定（合并时相等元素优先取左边的） |
| 排序方式 | 非原地排序（需要额外数组） |
| 自适应 | 否 非自适应（不论输入如何，都稳定在 $O(n \log n)$） |

## 优势与不足

### 优势
- 最坏情况下仍能保持 $O(n \log n)$，这是快排做不到的
- 稳定排序
- 对**顺序读写**友好，适合外部排序（处理超大数据）

### 不足
- 空间复杂度 $O(n)$，比快排/堆排占用更多内存
- 常数因子比快排大，实际运行速度通常慢于快排
- 递归深度 $\log n$，递归开销略大

## 应用场景

- 需要 **稳定排序** 且对最坏时间有要求的场景
- **外部排序**（数据量过大无法全部加载到内存）：归并排序的分治思想适合分段读写磁盘
- **链表排序**：归并排序对链表天然友好，无需额外空间
