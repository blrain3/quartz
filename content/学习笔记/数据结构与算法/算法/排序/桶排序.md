**桶排序（bucket sort）** 是分治策略的典型应用。它设置若干具有大小顺序的桶，每个桶对应一个数据范围，将数据分配到各个桶中；在每个桶内分别执行排序，最后按桶的顺序合并所有数据。

![Bucket_Sort.gif](https://tg.salix.eu.org/file/1776991859301_Bucket_Sort.gif)

## 算法流程

1. **确定桶的数量**：根据数据范围和数据量确定 $k$ 个桶
2. **分配数据到桶中**：遍历数组，将每个元素放入对应的桶（按值范围划分）
3. **桶内排序**：对每个桶内部执行排序（通常使用插入排序或快速排序）
4. **合并结果**：按桶的顺序将各桶中的元素依次取出

> 桶的数量 $k$ 和桶内排序算法的选择直接影响桶排序的效率。

## 代码实现

### Java
```java
void bucketSort(float[] nums) {
    int k = nums.length / 2;  // 桶数量
    if (k < 1) k = 1;
    List<List<Float>> buckets = new ArrayList<>();
    for (int i = 0; i < k; i++)
        buckets.add(new ArrayList<>());

    // 1. 将元素分配到各个桶中
    for (float num : nums) {
        int idx = (int)(num * k);  // 假设数据范围 [0, 1)
        buckets.get(idx).add(num);
    }

    // 2. 对每个桶内部排序
    for (List<Float> bucket : buckets)
        Collections.sort(bucket);

    // 3. 合并结果
    int i = 0;
    for (List<Float> bucket : buckets)
        for (float num : bucket)
            nums[i++] = num;
}
```

### C++
```cpp
void bucketSort(vector<float>& nums) {
    int k = nums.size() / 2;
    if (k < 1) k = 1;
    vector<vector<float>> buckets(k);

    for (float num : nums) {
        int idx = (int)(num * k);
        buckets[idx].push_back(num);
    }

    for (auto& bucket : buckets)
        sort(bucket.begin(), bucket.end());

    int i = 0;
    for (auto& bucket : buckets)
        for (float num : bucket)
            nums[i++] = num;
}
```

### Python
```python
def bucket_sort(nums: list[float]):
    """桶排序（假设数据范围 [0, 1)）"""
    k = len(nums) // 2  # 桶数量
    if k < 1: k = 1
    buckets = [[] for _ in range(k)]

    for num in nums:
        idx = int(num * k)
        buckets[idx].append(num)

    for bucket in buckets:
        bucket.sort()

    i = 0
    for bucket in buckets:
        for num in bucket:
            nums[i] = num
            i += 1
```

## 算法特性

| 特性 | 说明 |
|:---|:---|
| 时间复杂度 | 平均 $O(n + k)$；最坏 $O(n^2)$（所有元素集中在同一个桶） |
| 空间复杂度 | $O(n + k)$，需要维护桶和内部排序的额外空间 |
| 稳定性 | 是 稳定（取决于桶内排序算法，若使用稳定排序则稳定） |
| 排序方式 | 非原地排序 |
| 比较排序 | 包含比较（桶内排序通常基于比较） |

## 关键影响因素

### 桶的数量 $k$
- $k$ 越大，每个桶内元素越少，桶内排序越快
- 但桶太多会增加额外空间开销
- 通常取 $k \approx n$ 时效果较好

### 数据分布
- **均匀分布**时效果最好，接近 $O(n)$
- **数据极度分布不均**时退化为 $O(n^2)$

## 应用场景

- **浮点数排序**（可均匀映射到桶中）
- **大量数据均匀分布**的场景
- 外部排序的辅助手段
