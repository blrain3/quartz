**希尔排序（shell sort）** 是插入排序的改进版，也叫"递减增量排序"。它不急着排相邻的，而是先跳着排——把相隔一定距离的元素组成子序列分别做插入排序，然后逐步缩小这个间隔，最后间隔缩到 1 时，整个数组就差不多有序了，再做一次插入排序收尾。

## 算法原理

希尔排序的核心思想是：**让数组先局部有序，再全局有序**。

1. 选择一个增量序列（如 $n/2$、$n/4$、...、1）
2. 按照当前增量 $gap$，将数组分成若干子序列（每个子序列由间隔为 $gap$ 的元素组成）
3. 对每个子序列分别执行插入排序
4. 缩小增量 $gap$，重复步骤 2-3
5. 当 $gap = 1$ 时，执行一次完整的插入排序，数组完全有序

> 经过前面的排序，数组已经"基本有序"，最后一轮插入排序的效率非常高（接近 $O(n)$）。

## 增量序列的选择

| 增量序列 | 递推公式 | 时间复杂度 |
|:--------|:---------|:----------|
| Shell 原始序列 | $n/2, n/4, ..., 1$ | $O(n^2)$ |
| Hibbard 序列 | $2^k - 1$ | $O(n^{3/2})$ |
| Knuth 序列 | $(3^k - 1) / 2$ | $O(n^{3/2})$ |
| Sedgewick 序列 | 多种公式组合 | $O(n^{4/3})$ |

## 代码实现

### Java
```java
void shellSort(int[] nums) {
    int n = nums.length;
    // 增量序列：n/2, n/4, ..., 1
    for (int gap = n / 2; gap > 0; gap /= 2) {
        // 对每个子序列执行插入排序
        for (int i = gap; i < n; i++) {
            int base = nums[i], j = i - gap;
            while (j >= 0 && nums[j] > base) {
                nums[j + gap] = nums[j];
                j -= gap;
            }
            nums[j + gap] = base;
        }
    }
}
```

### Python
```python
def shell_sort(nums: list[int]):
    """希尔排序"""
    n = len(nums)
    gap = n // 2
    while gap > 0:
        for i in range(gap, n):
            base, j = nums[i], i - gap
            while j >= 0 and nums[j] > base:
                nums[j + gap] = nums[j]
                j -= gap
            nums[j + gap] = base
        gap //= 2
```

## 算法特性

| 特性 | 说明 |
|:---|:---|
| 时间复杂度 | 取决于增量序列，平均约 $O(n^{1.3})$，最坏 $O(n^2)$ |
| 空间复杂度 | $O(1)$，原地排序 |
| 稳定性 | 否 不稳定（分组排序可能打乱相等元素的相对顺序） |
| 排序方式 | 原地排序 |
| 自适应 | 是 自适应（基本有序时效率显著提升） |

## 希尔排序 vs 插入排序

| 对比维度 | 插入排序 | 希尔排序 |
|:--------|:--------|:--------|
| 时间复杂度 | $O(n^2)$ | $O(n^{1.3})$ ~ $O(n^2)$ |
| 优势 | 小规模数据、基本有序数据 | 大规模数据、乱序数据 |
| 交换/赋值次数 | 每轮移动距离大 | 通过增量跳跃减少移动距离 |
| 应用 | n < 50 时实用 | 中等规模数据的通用选择 |

## 应用场景

- 中等规模数据的排序（n 在几千到几万）
- 对**稳定性没有要求**的场景
- 嵌入式/资源受限环境（空间 $O(1)$，代码简单）
