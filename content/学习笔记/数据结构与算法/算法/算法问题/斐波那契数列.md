Wikipedia:[Fibonacci Sequence](https://en.wikipedia.org/wiki/Fibonacci_sequence)

该数列是 [[动态规划]] 问题的经典入门案例——递归解法存在大量重叠子问题，通过记忆化搜索或递推可降为 $O(n)$ 复杂度。

$$
F(n)=F(n−1)+F(n−2),F(1)=1, F(0)=0
$$

---
## 实现

### 递归

```Java
public class Fibonacci {
    public static int fibonacci(int n) {
        if (n <= 1) {
            return n;
        }
        return fibonacci(n - 1) + fibonacci(n - 2);
    }
    public static void main(String[] args) {
        int n = 10;
        System.out.println("前 " + n + " 个斐波那契数列：");
        for (int i = 0; i < n; i++) {
            System.out.print(fibonacci(i) + " ");
        }
    }
}
```
每一次递归都会产生重复计算，如计算$F(5)$和$F(4)$都需要递归计算$F(3)$，这样一来，$F(3)$就会被重复计算，时间复杂度为$O(2^n)$，呈指数级增长。空间复杂度为$O(n)$。
### 循环

```Java
public class Fibonacci {
    public static void main(String[] args) {
        int n = 10;
        int a = 0;
        int b = 1;
        System.out.print(a + " " + b + " ");
        for (int i = 2; i < n; i++) {
            int next = a + b;
            System.out.print(next + " ");
            a = b;
            b = next;
        }
    }
}
```
每个斐波那契数都只用计算一次，时间复杂度为$O(n)$，空间复杂度为$O(1)$。

### 动态规划

#### 数组

```Java
public class FibonacciDP {
    public static void main(String[] args) {
    
        int n = 10;
        int[] dp = new int[n];
        
        // 初始状态
        dp[0] = 0;
        dp[1] = 1;
        
        // 状态转移
        for (int i = 2; i < n; i++) {
            dp[i] = dp[i - 1] + dp[i - 2];
        }
        
        // 输出结果
        for (int i = 0; i < n; i++) {
            System.out.print(dp[i] + " ");
        }
    }
}
```
时间复杂度和空间复杂度都为$O(n)$。

## 矩阵快速幂

公式：

$$
A_n =
\begin{bmatrix}
F(n+1) & F(n)​ \\ F(n) & F(n−1)​
\end{bmatrix}
$$

```Java
public class FibonacciMatrix {

    // 矩阵乘法
    static long[][] multiply(long[][] a, long[][] b) {

        long[][] result = new long[2][2];

        result[0][0] =
                a[0][0] * b[0][0]
              + a[0][1] * b[1][0];

        result[0][1] =
                a[0][0] * b[0][1]
              + a[0][1] * b[1][1];

        result[1][0] =
                a[1][0] * b[0][0]
              + a[1][1] * b[1][0];

        result[1][1] =
                a[1][0] * b[0][1]
              + a[1][1] * b[1][1];

        return result;
    }

    // 矩阵快速幂
    static long[][] power(long[][] matrix, int n) {

        long[][] result = {
                {1, 0},
                {0, 1}
        };

        while (n > 0) {

            if ((n & 1) == 1) {
                result = multiply(result, matrix);
            }

            matrix = multiply(matrix, matrix);

            n >>= 1;
        }

        return result;
    }

    static long fibonacci(int n) {

        if (n <= 1) return n;

        long[][] base = {
                {1, 1},
                {1, 0}
        };

        long[][] result = power(base, n - 1);

        return result[0][0];
    }

    public static void main(String[] args) {

        System.out.println(fibonacci(10));
    }
}
```

## 快速幂

```Java
public class FastPower {
    public static long fastPow(long a, long n) {
        long result = 1;
        while (n > 0) {
            // 如果当前二进制位是 1
            if ((n & 1) == 1) {
                result *= a;
            }
            // 底数平方
            a *= a;
            // 指数右移一位
            n >>= 1;
        }
        return result;
    }
    public static void main(String[] args) {
        System.out.println(fastPow(2, 10));
    }
}
```
